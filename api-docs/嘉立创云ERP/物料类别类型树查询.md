# 物料类别类型树查询接口文档

## 1. 接口概述

接口名称：物料类别类型树查询

接口方法：getMaterialCategoryTypeTree

请求方式：POST

请求路径：/open/api/saas/erp/inventory/materialCategory/typeTreeV2

接口描述：查询物料类别类型树V2（保留物料类型分组+物料类别树），供物料库存

菜单左侧目录筛选

## 2. 请求参数

### 2.1 GetMaterialCategoryTypeTreeRequest 请求参数

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|enableStatus|Boolean|否|是否启用|
|materialType|Integer|否|物料类别的类型，1-基础物料；2-半成品|
|sortType|Integer|否|排序方式，1-名称升序；2-名称降序；3-创建时<br>间升序；4-创建时间降序|
|materialCategoryN|ameString|否|物料类别名称|

## 3. 响应参数

### 3.1 GetMaterialCategoryTypeTreeResult 响应结构

|**参数名**||**类型**|**必填**|**说明**|
|---|---|---|---|---|
|code|String||是|响应码|
|message|String||是|响应消息|
|data|List<Materi|alCategoryTypeTreeNode>|是|物料类别类型树列表，详见|

MaterialCategoryTypeTreeNode 对象

### 3.2 MaterialCategoryTypeTreeNode 物料类别类型树节点对象

|**参数名**|**类型**|**必**<br>**填**<br>**说明**|
|---|---|---|
|materialType|Integer|否物料类型|
|materialTypeName|String|否物料类型名称|
|materialCategoryId|Long|否物料类别id（业务命名）|
|materialCategoryName|String|否物料类别名称|
|materialCategoryPrefixCo|deString|否类别代号，用于生成物料编码|
|childrenList|List<MaterialCategoryTypeTreeNode>|否<br>子<br>集<br>，<br>节<br>点<br>结<br>构<br>同<br>MaterialCategoryTypeTreeNode|
