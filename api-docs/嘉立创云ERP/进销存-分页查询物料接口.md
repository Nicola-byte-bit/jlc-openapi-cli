# 分页查询物料接口文档

## 1. 接口概述

接口名称：分页查询物料

接口方法：getMaterialPageList

请求方式：POST

请求路径：/open/api/saas/erp/inventory/material/page

接口描述：根据多种条件分页查询物料信息，支持按物料编号、名称、规格、分类、

仓库等多维度筛选

## 2. 请求参数

### 2.1 GetMaterialPageRequest 请求参数

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|pageNum|Integer|是|当前页码，最小值为1|
|pageSize|Integer|是|每页数量，最大值为1000|
|materialId|Long|否|物料ID|
|keywordSearch|String|否|关键字搜索|
|materialCode|String|否|物料编号|
|mallNumber|String|否|商城编号|
|materialName|String|否|物料名称|
|specification|String|否|规格|
|materialType|Integer|否|物料类型|
|materialTypeList|List<Integer>|否|物料类型列表|
|enableStatus|Integer|否|启用状态|
|encapsulation|String|否|封装|
