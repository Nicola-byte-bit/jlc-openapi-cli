# 查询仓库-货架-库位树接口文档

## 1. 接口概述

接口名称：查询仓库-货架-库位树

接口方法：getWarehouseLocationTree

请求方式：POST

请求路径：/open/api/saas/erp/warehouse/warehouseLocationTreeV2

接口描述：查询仓库-货架-库位的树形结构，支持按仓库ID 和启用状态筛选

## 2. 请求参数

### 2.1 GetWarehouseLocationTreeRequest 请求参数

|---|---|---|---|
|onlyShowBelongShel|fFlagBoolean|否|是否只显示关联货架的库位|
|warehouseId|Long|否|仓库ID|
|enableStatus|Boolean|否|启用状态|
