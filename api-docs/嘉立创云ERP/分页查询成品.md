# 分页查询成品接口文档

## 1. 接口概述

接口名称：分页查询成品

接口方法：getGoodsPageList

请求方式：POST

请求路径：/open/api/saas/erp/goods/page

接口描述：根据多种条件分页查询成品信息，支持按成品名称、编号、规格、分类、

仓库等多维度筛选

## 2. 请求参数

### 2.1 GetGoodsPageRequest 请求参数

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|pageNum|Integer|是|当前页码，最小值为1|
|pageSize|Integer|是|每页数量，最大值为1000|
|keyword|String|否|关键字|
|goodsCodeList|List<String>|否|成品编号列表|
|goodsName|String|否|成品名称|
|spec|String|否|规格|
|remark|String|否|备注|
|enableStatus|Integer|否|启用状态|
|warehouseId|Long|否|仓库ID|
|productType|Integer|否|产品类型|
|createTimeStart|Date|否|创建时间开始|
|createTimeEnd|Date|否|创建时间结束|
