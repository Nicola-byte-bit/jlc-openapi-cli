# 采购订单明细分页查询接口文档

## 1. 接口概述

接口名称：分页查询采购订单明细

接口方法：getPurchaseOrderPageList

请求方式：POST

请求路径：/open/api/saas/erp/purchaseOrder/menuPage

接口描述：根据多种条件分页查询采购订单信息，支持按采购单号、物料信息、供应

商、时间范围等多维度筛选

## 2. 请求参数

### 2.1 GetPurchaseOrderPageRequest 请求参数

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|pageNum|Integer|是|当前页码，最小值为1|
|pageSize|Integer|是|每页数量，最大值为1000|
|purchaseOrderCode|String|否|采购订单单号|
|purchaseDetailCode|String|否|采购明细单号|
