# 文件标签列表查询接口文档

## 1. 接口概述

接口名称：文件标签列表查询

接口方法：listFileTag

请求方式：POST

请求路径：/open/api/saas/erp/file/listFileTag

接口描述：查询当前租户的文件标签字典，用于获知各接口的 fileTagIds 该填什么值：返回项的 bizKey 即标签标识（把该值填进各接口的 fileTagIds 即可）。tagType（1-常规，2-BOM 相 关）与 tagPurpose（1-文件标签，2-交付物标签）不传＝查全部。

## 2. 请求参数

### 2.1 ListFileTagRequest 请求参数

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|tagType|Integer|否|文件tag类型：1-常规，2-BOM相关；不传查全<br>部|
|tagPurpose|Integer|否|标签用途：1-文件标签，2-交付物标签；不传查<br>全部|

## 3. 响应参数

### 3.1 ListFileTagResult 响应结构

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|code|String|是|响应码|
|message|String|是|响应消息|
|data|List<FileTagResult<br>Data>|是|文件标签列表，详见FileTagResultData对象|

### 3.2 FileTagResultData 文件标签对象

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|bizKey|Long|是|标签id：即各接口fileTagIds入参所使用的标签<br>标识（把该值填进fileTagIds即可）|
|tagName|String|是|标签名称|
|tagType|Integer|是|文件tag类型：1-常规，2-BOM相关|
|tagPurpose|Integer|是|标签用途：1-文件标签，2-交付物标签|

|remark|String|否|备注|
|updateTime|String|否|修改时间|

## 4. 请求示例

{ "tagType": 1, "tagPurpose": 1 }

## 5. 响应示例

{ "code": "200", "message": "success", "data": [ { "bizKey": 5001, "tagName": "原理图", "tagType": 1, "tagPurpose": 1, "remark": "常规文件标签", "updateTime": "2026-07-20 10:30:00" } ] }

|---|---|---|---|
|200|成功|-|请求成功|
