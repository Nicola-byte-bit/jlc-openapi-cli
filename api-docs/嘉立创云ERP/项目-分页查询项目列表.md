# 分页查询项目接口文档

## 1. 接口概述

接口名称：分页查询项目

接口方法：getProjectPageList

请求方式：POST

请求路径：/open/api/saas/erp/project/page

接口描述：根据多种条件分页查询项目列表，支持按项目编号、名称、关键字、状

态、类型、负责人、开始时间、是否延期等维度筛选

## 2. 请求参数

### 2.1 GetProjectPageRequest 请求参数

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|pageNum|Integer|是|当前页码，最小值为1|
|pageSize|Integer|是|每页数量，最大值为1000|
|projectCode|String|否|项目编号|
|projectName|String|否|项目名称|
|keyword|String|否|关键字|
|projectStatus|Long|否|项目状态（1-待启动，2-研发中，3-已结项，4-<br>已取消，5-待排期）|
|projectType|Integer|否|项目类型|
|projectManagerId|Long|否|项目负责人id|
|projectStartTimeBegi|nDate|否|项目开始时间- 开始，格式yyyy-MM-dd<br>HH:mm:ss|
|projectStartTimeEnd|Date|否|项目开始时间- 结束，格式yyyy-MM-dd<br>HH:mm:ss|
|delayFlag|Boolean|否|是否延期|
