# 修改项目任务接口文档

## 1. 接口概述

接口名称：修改项目任务

接口方法：updateProjectTask

请求方式：POST

请求路径：/open/api/saas/erp/projectTask/update

接口描述：修改一个已存在的项目任务，支持更新任务基本信息、时间计划、负责人、风险等级 等

## 2. 请求参数

### 2.2 CustomFieldVO 自定义字段对象

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|fieldId|Long|是|自定义字段id。取「自定义字段定义查询」返回<br>的同一条字段记录的主键（该记录的<br>bizKey），必须与fieldCode指向同一个字段，<br>不可自行编造<br>i|
|fieldCode|String|是|自定义字段编码。取定义中的fieldCode，需与<br>fieldId指向同一字段|
|fieldName|String|否|自定义字段名称。可空，服务端以字段定义中的<br>名称为准|
|fieldType|Integer|是|自定义字段类型。1-文本，2-数值，3-单选，4-<br>多选，5-日期，6-快递进度，7-关联项目，8-链<br>接，9-附件。必须与定义中的fieldType一致，<br>否则该字段值无法正确解读<br>i|
|fieldValue|String|否|自定义字段值（字符串）。按fieldType填法：<br>1-文本 直接填文本内容；2-数值 填数字字符串，<br>如8.5（展示小数位取定义<br>customFieldDetail.decimalPlace）；5-日期 填<br>日期字符串，如2026-04-20 18:00:00（展示格<br>式取定义<br>customFieldDetail.dateFormatType）；8-链<br>接 填完整URL，如https://example.com/doc。<br>3-单选、4-多选 不依赖本字段，请改填<br>fieldOptionValue；6-快递进度 不依赖本字段，<br>请改填expressType/expressNo；7-关联项目、<br>9-附件 不依赖本字段|
|fieldOptionValue|List<String>|否|自定义字段选项值。仅3-单选、4-多选 需要填：<br>3-单选 只放1个元素（如["高"]），4-多选 放全<br>部选中项（如["选项A","选项B"]）。元素取值<br>必须来自定义<br>customFieldDetail.customFieldOptionList[].o<br>ptionValue，不能自造。其他类型留空数组即可|

|expressTypeName|String|否|快递公司名称。仅6-快递进度 使用，如 顺丰速<br>运，与expressType对应|
|expressNo|String|否|快递单号。仅6-快递进度 使用，如<br>SF1234567890|
|expressPhone|String|否|快递查询手机号（脱敏）。仅6-快递进度 使用，<br>用于快递平台查询，可空|
|expressPhoneDes|String|否|快递查询手机号（加密）。仅6-快递进度 使用，<br>由服务端加解密，第三方一般无需填写|
|projectId|Long|否|关联项目id。仅7-关联项目 使用，填项目主键|
|projectaCode|String|否|关联项目编号。仅7-关联项目 使用|
