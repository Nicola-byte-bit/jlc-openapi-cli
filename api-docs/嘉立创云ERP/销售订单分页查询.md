# 分页查询销售订单接口文档

## 1. 接口概述

接口名称：分页查询销售订单

接口方法：getOrderPageList

请求方式：POST

请求路径：/open/api/saas/erp/order/menuPage

接口描述：根据多种条件分页查询销售订单信息，支持按订单号、客户、商品、时间 范围等多维度筛选
