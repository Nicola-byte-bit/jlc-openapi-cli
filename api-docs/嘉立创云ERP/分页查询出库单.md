# 分页查询出库单接口文档

## 1. 接口概述

接口名称：分页查询出库单

接口方法：getOutStockPageList

请求方式：POST

请求路径：/open/api/saas/erp/inventory/outStock/page

接口描述：根据多种条件分页查询出库单信息，支持按出库单号、出库类型、仓库、

状态、时间范围等多维度筛选
