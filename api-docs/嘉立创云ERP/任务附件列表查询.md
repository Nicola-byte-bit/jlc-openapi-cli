# 任务附件列表查询接口文档

## 1. 接口概述

接口名称：任务附件列表查询

接口方法：listTaskAttachment

请求方式：POST

请求路径：/open/api/saas/erp/file/listTaskAttachment

接口描述：根据任务 bizKey 查询该任务下的附件列表。

## 2. 请求参数

### 2.1 ListTaskAttachmentRequest 请求参数

|**参数名**||**类型**|**必填**||**说明**|
|---|---|---|---|---|---|
|taskBizKey|Long||是|任务bizKey||

## 3. 响应参数

### 3.1 ListTaskAttachmentResult 响应结构

|**参数名**||**类型**|**必填**|**说明**|
|---|---|---|---|---|
|code|String||是|响应码|
|message|String||是|响应消息|
|data|List<TaskA|ttachmentResultData>|是|任<br>务<br>附<br>件<br>列<br>表<br>，<br>详<br>见<br>TaskAttachmentResultData对象|

### 3.2 TaskAttachmentResultData 任务附件对象

|**参数名**|**类型**|**必填**||**说明**|
|---|---|---|---|---|
|fileId|Long|是|文件id（该附件的唯|一标识）|
|fileAccessId|String|是|文件阿里云id||
|fileName|String|是|文件名||

|fileExtension|String|否|文件后缀|
|fileSize|Long|否|文件大小KB|
|uploadTime|Date|否|文件上传时间，格式yyyy-MM-dd HH:mm:ss|
|uploaderName|String|否|上传人名称|
|thumbnailUrl|String|否|缩略图url|
