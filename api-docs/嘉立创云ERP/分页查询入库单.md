# 分页查询入库单接口文档

## 1. 接口概述

接口名称：分页查询入库单

接口方法：getInStockPageList

请求方式：POST

请求路径：/open/api/saas/erp/inventory/inStock/page

接口描述：根据多种条件分页查询入库单信息，支持按入库单号、入库类型、仓库、

状态、时间范围等多维度筛选

## 2. 请求参数

### 2.1 GetInStockPageRequest 请求参数

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|pageNum|Integer|是|当前页码，最小值为1|
|pageSize|Integer|是|每页数量，最大值为1000|
|inStockCode|String|否|入库单号|
|statusList|List<Integer>|否|状态列表|
|inStockDateBegin|Date|否|入库日期开始|
|inStockDateEnd|Date|否|入库日期结束|
|createTimeBegin|Date|否|创建时间开始|
|createTimeEnd|Date|否|创建时间结束|
|remark|String|否|备注|
|goodsCode|String|否|成品编号|
|goodsName|String|否|成品名称|
|spec|String|否|规格|
|materialName|String|否|物料名称|
|materialCode|String|否|物料编号|

|mallNumber|String|否|商城编号|
