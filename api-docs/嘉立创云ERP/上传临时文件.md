# 上传临时文件接口文档

## 1. 接口概述

接口名称：上传临时文件

接口方法：uploadTmpFile

请求方式：POST

请求路径：/open/api/saas/erp/file/uploadTmpFile

接口描述：上传一个无目录归属的临时文件（不做目录解析与同名校验），返回文件 id；该

id 可直接用于「创建项目任务」的 taskFileBizKeys （即先传附件、再建任务）。请求

Content-Type 为 multipart/form-data

## 2. 请求参数

### 2.1 UploadTmpFileRequest 请求参数

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|fileTagIds<br>i|List<Long>|否|标签id列表（由getFileTagList查询得到）；不<br>传表示不打标签，标签随本次上传直接生效|
|file|MultipartFile|是|待上传的文件|

## 3. 响应参数

### 3.1 UploadTmpFileResult 响应结构

|**参数名**|**类型**|**必填**||**说明**|
|---|---|---|---|---|
|code|String|是|响应码||
|message|String|是|响应消息||
|data|Long|是|上传成功后的文件id <br>taskFileBizKeys）|（可直接作为创建项目任务的|

## 4. 请求示例

{ "fileTagIds": [5001, 5002], "file": " 设 计 图 .pdf" } **5. 响应示例** { "code": "200", "message": "success", "data": 30001

{ }
