# 新增出库单接口文档

## 1. 接口概述

接口名称：新增出库单

接口方法：addOutStock

请求方式：POST

请求路径：/open/api/saas/erp/inventory/outStock/add

接口描述：创建出库单，支持物料出库和成品出库，可关联销售订单等业务单据

## 2. 请求参数

### 2.1 AddOutStockRequest 请求参数

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|outStockCode|String|否|出库单号|
|outStockType|Integer|否|出库类型|
|outWarehouseId|Long|否|出库仓库ID|
|consignee|String|否|收货人|
|outStockDate|String|否|出库日期|
|associatedBusinessId|Long|否|关联业务ID|
|associatedBusinessCode|String|否|关联业务编号|
|associatedBusinessType|Integer|否|关联业务类型（1:采购单2:生产订<br>单3:盘点单4:退料单5:销售单6:<br>调拨单7:借调出库单8:发货单）|
|customField|List<CustomFieldVO>|否|自定义字段，详见CustomFieldVO<br>对象|
|remark|String|否|备注|
|materialOutStockDetailLis|tList<MaterialOutStockDetailVO>|否|物料出库明细列表，详见<br>MaterialOutStockDetailVO 对象|
|goodsOutStockDetailList|List<GoodsOutStockDetailVO>|否|成品出库明细列表，详见<br>GoodsOutStockDetailVO 对象|
