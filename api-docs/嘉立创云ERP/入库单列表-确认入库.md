# 确认入库接口文档

## 1. 接口概述

接口名称：确认入库

接口方法：confirmInbound

请求方式：POST

请求路径：/open/api/saas/erp/inventory/inStock/inbound

接口描述：确认入库单入库操作，将待入库状态的入库单变更为已入库状态

## 2. 请求参数

### 2.1 ConfirmInboundRequest 请求参数

|**参数名**||**类型**|**必填**||**说明**|
|---|---|---|---|---|---|
|inStockId|Long||是|入库单ID||

## 3. 响应参数

### 3.1 ConfirmInboundResult 响应结构

|**参数名**|**类型**|**必填**||**说明**|
|---|---|---|---|---|
|code|String|是|响应码||
|message|String|是|响应消息||
|data|Void|否|无返回数据||

## 4. 请求示例

{

- "inStockId": 123456

- }

## 5. 响应示例

{ "code": "200", "message": "success", "data": null }

## 6. 错误码说明

|**参数名**|**类型**|**必填**||**说明**|
|---|---|---|---|---|
|200|成功|-|请求成功||
|400|参数错误|-|请求参数不合法||
|401|未授权|-|未登录或token 失效||
|403|禁止访问|-|无权限访问该接口||
|500|服务器错误|-|服务器内部错误||
