# 项目工时分页查询接口文档

## 1. 接口概述

接口名称：项目工时分页查询

接口方法：getProjectTaskWorkingHoursPageList

请求方式：POST

请求路径：/open/api/saas/erp/projectTaskWorkingHours/page

接口描述：分页查询项目登记工时列表，可按任务id 筛选

## 2. 请求参数

### 2.1 GetProjectTaskWorkingHoursPageRequest 请求参数

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|taskId|Long|否|任务id|
|pageNum|Integer|是|当前页码，最小值为1|
|pageSize|Integer|是|每页条数，最大值为1000|
