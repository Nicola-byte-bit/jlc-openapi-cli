# 批量新增物料接口文档

## 1. 接口概述

接口名称：批量新增物料

接口方法：batchAddMaterial

请求方式：POST

请求路径：/open/api/saas/erp/inventory/material/batchAdd

接口描述：通过Excel 文件批量导入物料，按固定模板解析。请求Content-Type 为

multipart/form-data

## 2. 请求参数

### 2.1 BatchAddMaterialRequest 请求参数

||**参数名**|**类型**|**必填**||**说明**|
|---|---|---|---|---|---|
|file||MultipartFile|是|物料导入Excel 文件，|按固定模板格式|

## 3. 响应参数

### 3.1 BatchAddMaterialResult 响应结构

|**参数名**|**类型**|**必填**||**说明**||
|---|---|---|---|---|---|

|message|String|是|响应消息|||
|data|BatchAddMaterialResul|tData是|批<br>量<br>导<br>入<br>结<br>BatchAddMaterialR|果<br>数<br>据<br>，<br>esultData 对象|详<br>见|

|**参数名**|**类型**|**必填**|**说明**||
|---|---|---|---|---|

## 4. 请求示例

Content-Type: multipart/form-data
