# 查询项目任务详情接口文档

## 1. 接口概述

接口名称：查询项目任务详情

接口方法：getProjectTaskDetail 请求方式：POST

请求路径：/open/api/saas/erp/projectTask/detail 接口描述：根据任务 id 或任务编码查询项目任务的详细信息

## 2. 请求参数

### 2.1 TaskDetailReqDTO 请求参数

|**参数名**|**类型**|**必填**||**说明**|
|---|---|---|---|---|
|taskId|Long|否|任务id||
|taskCode|String|否|任务编码||

## 3. 响应参数

### 3.1 HttpResult<TaskDetailRespDTO> 响应结构

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|code|String|是|响应码|
|message|String|是|响应消息|
|success|Boolean|是|是否成功|
|data|TaskDetailRespDT<br>O|是|任务详情数据，详见TaskDetailRespDTO对象|
