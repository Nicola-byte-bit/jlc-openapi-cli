# 查询销售订单详情接口文档

## 1. 接口概述

接口名称：查询销售订单详情

接口方法：getOrderDetail

请求方式：POST

请求路径：/open/api/saas/erp/order/detail

接口描述：根据订单业务ID 查询销售订单的详细信息

## 2. 请求参数

### 2.1 GetOrderDetailRequest 请求参数

|**参数名**||**类型**|**必填**||**说明**|
|---|---|---|---|---|---|
|orderId|Long||是|订单业务ID||
