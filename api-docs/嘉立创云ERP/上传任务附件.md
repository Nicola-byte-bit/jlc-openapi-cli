# 上传任务附件接口文档

## 1. 接口概述

接口名称：上传任务附件

接口方法：uploadTaskAttachment

请求方式：POST

请求路径：/open/api/saas/erp/file/uploadTaskAttachment

接口描述：把文件上传到任务对应的附件文件夹，返回上传后的文件 id。若传入 fileTagIds，平 台会在上传成功后自动为该文件补打标签（该场景下若补打标签失败，平台返回 code=1005 且 message 以「文件已上传成功」开头，此时文件已存在，请勿重传，改用 updateFileRelatedTag 补打标签）。请求 Content-Type 为 multipart/form-data

## 2. 请求参数

### 2.1 UploadTaskAttachmentRequest 请求参数

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|taskBizKey|Long|是|任务id|
|fileTagIds<br>i|List<Long>|否|标签id列表（由getFileTagList查询得到）；不<br>传表示不打标签；传入时平台在上传成功后自动<br>补打标签|
|file|MultipartFile|是|待上传的文件|

## 3. 响应参数

### 3.1 UploadTaskAttachmentResult 响应结构

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|code|String|是|响应码|
|message|String|是|响应消息|
|data|Long|是|上传成功后的文件id|

## 4. 请求示例

{ "taskBizKey": 20001, "fileTagIds": [5001, 5002], "file": "设计图.pdf"

<mark>}</mark>

## 5. 响应示例

{ "code": "200", "message": "success", "data": 30001 }

## 6. 错误码说明

|**参数名**|**类型**|**必填**||**说明**|
|---|---|---|---|---|
|200|成功|-|请求成功||
|400|参数错误|-|请求参数不合法||
|401|未授权|-|未登录或token失效||
|403|禁止访问|-|无权限访问该接口||
|500|服务器错误|-|服务器内部错误||
