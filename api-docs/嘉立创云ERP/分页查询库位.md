# 分页查询库位接口文档

## 1. 接口概述

接口名称：分页查询库位

接口方法：getWarehouseLocationPageList

请求方式：POST

请求路径：/open/api/saas/erp/warehouse/warehouseLocationPage

接口描述：分页查询库位列表，支持按库位名称、编号、启用状态、货架、仓库等条 件筛选

## 2. 请求参数

### 2.1 GetWarehouseLocationPageRequest 请求参数

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|pageNum|Integer|是|当前页码，最小值为1|
|pageSize|Integer|是|每页数量，最大值为1000|
|keyword|String|否|关键字|
|warehouseLocationName|String|否|库位名称|
|warehouseLocationCode|String|否|库位编号|
|enableStatus|Boolean|否|启用状态|
|shelfId|Long|否|货架ID|
|warehouseId|Long|否|仓库ID|
|warehouseType|Integer|否|仓库类型|
