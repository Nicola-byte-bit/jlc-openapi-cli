# 批量新增成品接口文档

## 1. 接口概述

接口名称：批量新增成品

接口方法：batchAddGoods

请求方式：POST

请求路径：/open/api/saas/erp/goods/batchAdd

接口描述：通过Excel 文件批量导入成品，按固定模板解析。请求Content-Type 为

multipart/form-data

## 2. 请求参数

### 2.1 BatchAddGoodsRequest 请求参数

||**参数名**|**类型**|**必填**||**说明**|
|---|---|---|---|---|---|
|file||MultipartFile|是|成品导入Excel 文件，|按固定模板格式|

## 3. 响应参数

### 3.1 BatchAddGoodsResult 响应结构

|**参数名**|**类型**<br>**必填**|**说明**||
|---|---|---|---|
|code|String<br>是|响应码||
|message|String<br>是|响应消息||
|data|BatchAddGoodsResultData是|批<br>量<br>导<br>入<br>结<br>果<br>数<br>据<br><br>BatchAddGoodsResultData 对象|，<br>详<br>见|

### 3.2 BatchAddGoodsResultData 批量导入结果数据对象

|**参数名**||**类型**|**必填**||**说明**||
|---|---|---|---|---|---|---|
|successCount|Integer||是|成功数量|||
|failCount|Integer||是|失败数量|||
|failList|List<BatchA|ddGoodsFailItemData>|是|失<br>败<br>列<br>BatchAddGoods|表<br>，<br>详<br>FailItemData 对象|见|

### 3.3 BatchAddGoodsFailItemData 失败项数据对象

|**参数名**|**类型**|**必填**||**说明**|
|---|---|---|---|---|
|rowSortIndex|Integer|是|失败所在行号||
|result|String|是|失败原因||

## 4. 请求示例

Content-Type: multipart/form-data

file: 成品导入模板.xlsx

## 5. 响应示例

{ "code": "200", "message": "success", "data": { "successCount": 10, "failCount": 1, "failList": [ { "rowSortIndex": 5, "result": "成品编号重复" } ] } }
