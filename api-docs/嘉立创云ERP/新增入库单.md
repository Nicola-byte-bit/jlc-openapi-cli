# 新增入库单接口文档

## 1. 接口概述

接口名称：新增入库单

接口方法：addInStock

请求方式：POST

请求路径：/open/api/saas/erp/inventory/inStock/add

接口描述：创建入库单，支持物料入库和成品入库，可关联采购订单等业务单据

## 2. 请求参数

### 2.1 AddInStockRequest 请求参数

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|inStockCode|String|否|入库单号|
|inStockType|Integer|否|入库类型（1:采购单入库2:生产完工入<br>库3:成品盘盈4:原料盘盈5:退料单入<br>库6:成品其他入库7:物料其他入库8:<br>调拨单入库9:借调入库10:直接调整库<br>存入库11:成品销售退货12:发货单退<br>货）|
|inWarehouseId|Long|否|入库仓库ID|
|inStockDate|String|否|入库日期|
|remark|String|否|备注|
|materialInStockDetailLis|tList<MaterialInStockDetailVO>|否|物料入库明细列表，详见<br>MaterialInStockDetailVO 对象|
|goodsInStockDetailList|List<GoodsInStockDetailVO>|否|成品入库明细列表，详见<br>GoodsInStockDetailVO 对象|
|inStockFlag|Boolean|否|入库标识|
