# 成品目录树查询接口文档

## 1. 接口概述

接口名称：成品目录树查询

接口方法：getGoodsConfigTree

请求方式：POST

请求路径：/open/api/saas/erp/goods/config/tree

接口描述：查询成品目录树（商品分类，goodsConfigType=2），供成品库存菜单

左侧目录筛选

## 2. 请求参数

### 2.1 GetGoodsConfigTreeRequest 请求参数

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|goodsConfigType|Integer|否|类型（1-商品单位，2-商品分类），成品目录固定<br>传2|
|parentId|Long|否|父级id（-1 表示一级；传入某节点bizKey 则查其<br>直接子级）|
|parentIds|List<Long>|否|父级id 集合（-1 表示一级；传入某节点bizKey 则<br>查其直接子级）|
|keyword|String|否|关键字|

## 3. 响应参数

### 3.1 GetGoodsConfigTreeResult 响应结构

|**参数名**||**类型**|**必填**||**说明**|
|---|---|---|---|---|---|
|code|String||是|响应码||

|message|String|是|响应|消息|||
|data|List<GoodsConfigTreeNode>|是|成<br>Goo|品<br>目<br>录<br>树<br>列<br>表<br><br>dsConfigTreeNode 对象|，<br>详|见|

### 3.2 GoodsConfigTreeNode 成品目录树节点对象

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|goodsConfigId|Long|是|商品设置id（业务命名）|
|parentId|Long|是|父级id（-1 表示一级）|
|goodsConfigName|String|是|名称|
|goodsConfigValue|String|否|值|
|remark|String|否|备注|
|childrenList|List<GoodsConfigTreeNode>|否|子<br>节<br>点<br>列<br>表<br>，<br>节<br>点<br>结<br>构<br>同<br>GoodsConfigTreeNode|
