# 分页查询仓库接口文档

## 1. 接口概述

接口名称：分页查询仓库

接口方法：getWarehousePageList

请求方式：POST

请求路径：/open/api/saas/erp/warehouse/menuPage

接口描述：分页查询仓库列表，支持按仓库编号、名称、类型、启用状态、地区等条 件筛选

## 2. 请求参数

### 2.1 GetWarehousePageRequest 请求参数

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|pageNum|Integer|是|当前页码，最小值为1|
|pageSize|Integer|是|每页数量，最大值为1000|
|warehouseCode|String|否|仓库编号|
|warehouseName|String|否|仓库名称|
|warehouseType|Integer|否|仓库类型（1:仓库，2:嘉立创SMT 私有库）|
|enableStatus|Boolean|否|启用状态|
|defaultFlag|Boolean|否|是否默认|
|provinceName|String|否|省名称|
|cityName|String|否|城市名称|
|districtName|String|否|区名称|
|createTimeStart|Date|否|创建时间-开始|
|createTimeEnd|Date|否|创建时间-结束|
