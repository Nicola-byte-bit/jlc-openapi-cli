# 项目状态变更接口文档

## 1. 接口概述

接口名称：项目状态变更

接口方法：updateProjectStatus 请求方式：POST

请求路径：/open/api/saas/erp/project/updateStatus

接口描述：把指定项目切换到目标状态。projectStatus 为系统固定枚举：1-待启动、2-研发中、 3-已结项、4-已取消、5-待排期。成功时响应信封的 data 为 null。

## 2. 请求参数

### 2.1 UpdateProjectStatusRequest 请求参数

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|projectId|Long|是|项目id|
|projectStatus|Long|是|项目状态。系统固定枚举：1-待启动，2-研发<br>中，3-已结项，4-已取消，5-待排期；传入其他<br>值会被拒绝|

## 3. 响应参数

### 3.1 UpdateProjectStatusResult 响应结构

|**参数名**|**类型**|**必填**||**说明**|
|---|---|---|---|---|
|code|String|是|响应码||
|message|String|是|响应消息||
|success|Boolean|是|是否成功||

## 4. 请求示例

{ "projectId": 10001, "projectStatus": 2 }

## 5. 响应示例

{ "code": "200", "message": "success", "success": true }

## 6. 错误码说明

|**参数名**|**类型**|**必填**||**说明**|
|---|---|---|---|---|
|200|成功|-|请求成功||
|400|参数错误|-|请求参数不合法||
|401|未授权|-|未登录或token失效||
|403|禁止访问|-|无权限访问该接口||
|500|服务器错误|-|服务器内部错误||
