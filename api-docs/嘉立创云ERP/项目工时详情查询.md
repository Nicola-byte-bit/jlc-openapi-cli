# 项目工时详情查询接口文档

## 1. 接口概述

接口名称：项目工时详情查询

接口方法：getProjectTaskWorkingHoursDetail

请求方式：POST

请求路径：/open/api/saas/erp/projectTaskWorkingHours/detail

接口描述：根据业务主键ID 查询项目工时的详细信息

## 2. 请求参数

### 2.1 GetProjectTaskWorkingHoursDetailRequest 请求参数

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|projectTaskWorkingHoursIdLong||是|工时记录id（业务命名，与bizKey 二选一）|

## 3. 响应参数

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
