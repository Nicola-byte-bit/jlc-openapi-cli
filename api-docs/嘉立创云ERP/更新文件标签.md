# 更新文件标签接口文档

## 1. 接口概述

接口名称：更新文件标签

接口方法：updateFileRelatedTag

请求方式：POST

请求路径：/open/api/saas/erp/file/updateFileRelatedTag

接口描述：按文件 id（resourceId）覆盖式更新该文件的「文件侧」标签。返回值为「被任务交 付物占用（task_id≠�0）、本次未能删除的锁定标签 id 列表」，注意它并不是「生效后的标签列 表」。fileTagIds 不传或传空列表表示清空该文件「文件侧」标签（被任务交付物承载的标签不 会被删除）。标签 id 由 getFileTagList 查询得到。

## 2. 请求参数

### 2.1 UpdateFileRelatedTagRequest 请求参数

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|resourceId|Long|是|文件id|
|fileTagIds|List<Long>|否|标签id列表（由getFileTagList查询得到）；不<br>传或传空列表表示清空该文件「文件侧」标签，<br>被任务交付物承载的标签不会被删除|

## 3. 响应参数

### 3.1 UpdateFileRelatedTagResult 响应结构

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|code|String|是|响应码|
|message|String|是|响应消息|
|data|List<Long>|是|被任务交付物占用（task_id≠�0）、本次未能删<br>除的锁定标签id列表；不是「生效后的标签列<br>表」，无锁定时为空数组|

## 4. 请求示例

{ "resourceId": 30002, "fileTagIds": [5001, 5002]

<mark>}</mark>

## 5. 响应示例

{ "code": "200", "message": "success", "data": [5002] }
