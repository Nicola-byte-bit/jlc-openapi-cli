# 成品库存菜单分页查询接口文档

## 1. 接口概述

接口名称：成品库存菜单分页查询

接口方法：getGoodsStockMenuPageList

请求方式：POST

请求路径：/open/api/saas/erp/inventory/stock/goods/menuPage

接口描述：分页查询成品库存菜单，保留左侧商品分类分组筛选

（categoryValue/categoryValues）和关键字查询能力

## 2. 请求参数

|unitName|String|否|单位名称|
