# 文件夹列表查询接口文档

## 1. 接口概述

接口名称：文件夹列表查询

接口方法：getDirectoryList

请求方式：POST

请求路径：/open/api/saas/erp/file/directoryList

接口描述：查询指定文件夹（resourceId）下的子目录与文件列表，支持按名称模糊匹配、

按文件夹/文件过滤、按标签过滤以及指定排序方式。目录与文件共用同一行数据结构，通过

isDirectory 区分。

## 2. 请求参数

### 2.1 GetDirectoryListRequest 请求参数

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|resourceId|Long|是|文件夹id（要查询哪个文件夹下的子目录/文件）|
|isDirectory|Boolean|否|是否只查文件夹：true-只查文件夹，false-只查文<br>件，不传-查全部|
|sortType|Integer|否|排序方式（1：名称升序,2名称降序,3创建时间升<br>序,4 创建时间降序,5 类型升序,6 类型降序<br>FileListSortTypeEnum）|
|name|String|否|名称（模糊匹配）|
|tagId|Long|否|标签id（不传则不过滤；传则文件只查绑定了该标<br>签的）|

## 3. 响应参数

### 3.1 GetDirectoryListResult 响应结构

|**参数名**<br>**类型**|**必填**|**说明**|
|---|---|---|

|code|String<br>|是|响应码|
|message|String<br>|是|响应消息|
|data|List<DirectoryListResultData>|是|子<br>目<br>录<br>/<br>文<br>件<br>列<br>表<br>，<br>详<br>见<br>DirectoryListResultData对象|

### 3.2 DirectoryListResultData 文件夹列表对象（目录与文件共用）

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|isDirectory|Boolean|是|是否文件夹|
|directoryNameBiz<br>i|String|否|目录名称（关联业务节点名称），<br>isDirectory=true时返回|
|fileName<br>i|String|否|文件名称，isDirectory=false时返回|
|fileExtension<br>i|String|否|文件后缀，isDirectory=false时返回|
|fileAccessId|String|否|文件阿里云id，isDirectory=false时返回|
|appId<br>i|Long|是|应用id|
|fileSize<br>i|Long|否|文件大小KB|
|fileTagIds|List<Long>|否|标签id列表|
|resourceId|Long|是|节点id （该行自身的唯一标识）：<br>isDirectory=true时为目录id，可作为下一次查<br>询本目录的resourceId传回；isDirectory=false<br>时为文件id，用于下载/删除等文件操作|
|createByName|String|否|创建人名称|
|createTime|Date|否|创建时间，格式yyyy-MM-dd HH:mm:ss|
|thumbnailUrl|String|否|缩略图url|
|isArchive|Integer|否|是否归档：0-未归档，1-已归档|
|fileNum|Integer|否|文件数量（目录类型返回：下一层权限可见的文件<br>数）|
|hasDfmParseResult|Boolean|否|是否有DFM解析结果（仅解析成功为true；仅文<br>件类型返回）|
|associateBizId|Long|否|关联业务id（如关联任务id）|
|associateBizName|String|否|关联业务名称（如关联任务名称）|
|associateBizType|Integer|否|关联业务类型（FileAssociateBizTypeEnum）：<br>1-任务|
|customField|List<CustomFieldVO>|否|自定义字段列表（仅文件类型返回），结构同<br>CustomFieldVO|
