# 分页查询项目任务接口文档

## 1. 接口概述

接口名称：分页查询项目任务

接口方法：getProjectTaskPageList 请求方式：POST

请求路径：/open/api/saas/erp/projectTask/page

接口描述：根据多种条件分页查询项目任务列表，支持按项目 ID、任务编码、任务名称、任务风 险、任务状态（支持多选）、修改时间区间等维度筛选；支持按自定义字段筛选 （customFieldFilterConditions，多个条件之间为 AND 关系）：只有 fieldId 必填，取自「自 定义字段定义查询」返回的 bizKey，按字段类型选用对应的取值字段（1-文本用 fieldConditionValue 精确匹配；2-数值用 conditionStartValue/conditionEndValue 闭区间； 3-单选、4-多选用 fieldOptionConditionValue 命中任一即可；5-日期用 conditionStartValue/conditionEndValue 闭区间且格式须与存储值一致），不支持 6-快递进 度/7-关联项目/8-链接/9-附件；不传或传空数组表示不限
