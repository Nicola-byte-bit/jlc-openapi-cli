# 登记项目工时接口文档

## 1. 接口概述

接口名称：登记项目工时

接口方法：addProjectTaskWorkingHours

请求方式：POST

请求路径：/open/api/saas/erp/projectTaskWorkingHours/add

接口描述：登记一条项目工时记录，记录任务的实际投入时间和工作内容

## 2. 请求参数

### 2.1 AddProjectTaskWorkingHoursRequest 请求参数

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|projectNodeTaskId|Long|是|任务id|
|customerId|Long|是|客户（员工）id|
|beginTime|Date|否|开始时间，格式yyyy-MM-dd HH:mm:ss|
|actualInvestmentTim|eBigDecimal|是|实际投入时间|
|workDesc|String|否|工作内容描述|

## 3. 响应参数

### 3.1 AddOrUpdateProjectTaskWorkingHoursResult 响应结构

|**参数名**|**类型**|**必填**||**说明**|
|---|---|---|---|---|
|code|String|是|响应码||
|message|String|是|响应消息||
|success|Boolean|是|是否成功||

## 4. 请求示例

{ "projectNodeTaskId": 20001, "customerId": 3001, "beginTime": "2026-07-01 09:00:00", "actualInvestmentTime": 8.5, "workDesc": "完成工时登记接口开发" }

## 5. 响应示例

{ "code": "200", "message": "success", "success": true }

## 6. 错误码说明

|**参数名**|**类型**|**必填**||**说明**|
|---|---|---|---|---|
|200|成功|-|请求成功||
|400|参数错误|-|请求参数不合法||
|401|未授权|-|未登录或token 失效||
|403|禁止访问|-|无权限访问该接口||
|500|服务器错误|-|服务器内部错误||
