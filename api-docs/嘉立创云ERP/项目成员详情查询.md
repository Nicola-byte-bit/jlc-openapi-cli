# 项目成员详情查询接口文档

## 1. 接口概述

接口名称：项目成员详情查询

接口方法：getProjectMemberDetail

请求方式：POST

请求路径：/open/api/saas/erp/project/memberDetailInProject

接口描述：根据项目id 查询项目成员详情，包含成员总数与成员列表

## 2. 请求参数

### 2.1 GetProjectMemberDetailRequest 请求参数

|**参数名**||**类型**|**必填**||**说明**|
|---|---|---|---|---|---|
|projectId|Long||是|项目id||

## 3. 响应参数

### 3.1 GetProjectMemberDetailResult 响应结构

|**参数名**|**类型**<br>**必填**|**说明**|
|---|---|---|
|code|String<br>是|响应码|
|message|String<br>是|响应消息|
|data|ProjectMemberDetailRespData是|项<br>目<br>成<br>员<br>详<br>情<br>数<br>据<br>，<br>详<br>见<br>ProjectMemberDetailRespData 对象|

### 3.2 ProjectMemberDetailRespData 项目成员详情对象

|**参数名**||**类型**|**必填**||**说明**|
|---|---|---|---|---|---|
|count|Integer||是|成员总数||

memberList

List<ProjectMemberItem>是 成员列表，详见ProjectMemberItem 对象

### 3.3 ProjectMemberItem 成员信息对象

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|memberId|Long|是|成员id|
|customerId|Long|否|客户（员工）id|
|projectId|Long|否|项目id|
|customerName|String|否|客户（员工）名称|
|positionId|Long|否|岗位id|
|positionName|String|否|岗位名称|
|projectJoinTime|String|否|加入项目时间，格式yyyy-MM-dd HH:mm:ss|
|projectLeaveTime|String|否|离开项目时间，格式yyyy-MM-dd HH:mm:ss|
|remark|String|否|备注|
|rolePermission|Integer|否|角色权限（1-普通成员，2-项目管理员）|
|manageFlag|Boolean|否|是否为负责人|
