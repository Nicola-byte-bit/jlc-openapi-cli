# 删除项目工时接口文档

## 1. 接口概述

接口名称：删除项目工时

接口方法：deleteProjectTaskWorkingHours

请求方式：POST

请求路径：/open/api/saas/erp/projectTaskWorkingHours/delete

接口描述：根据业务主键ID 删除一条项目工时记录

## 2. 请求参数

### 2.1 DeleteProjectTaskWorkingHoursRequest 请求参数

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|projectTaskWorkingHoursIdLong||是|工时记录id（业务命名，与bizKey 二选一）|

## 3. 响应参数

### 3.1 DeleteProjectTaskWorkingHoursResult 响应结构

|**参数名**|**类型**|**必填**||**说明**|
|---|---|---|---|---|
|code|String|是|响应码||
|message|String|是|响应消息||
|success|Boolean|是|是否成功||

## 4. 请求示例

{

- "projectTaskWorkingHoursId": 50001

- }

## 5. 响应示例

{ "code": "200", "message": "success", "success": true }
