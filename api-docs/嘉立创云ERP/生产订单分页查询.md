# 分页查询生产订单接口文档

## 1. 接口概述

接口名称：分页查询生产订单

接口方法：getProductionOrderPageList

请求方式：POST

请求路径：/open/api/saas/erp/productionOrder/menuPage

接口描述：根据多种条件分页查询生产订单信息，支持按生产订单号、销售订单、商

品、时间范围等多维度筛选

## 2. 请求参数

### 2.1 GetProductionOrderPageRequest 请求参数

|**参数名**|**类型**|**必填**|**说明**|
|---|---|---|---|
|pageNum|Integer|是|当前页码，最小值为1|
|pageSize|Integer|是|每页数量，最大值为1000|
|productionOrderCode|String|否|生产订单编号|
