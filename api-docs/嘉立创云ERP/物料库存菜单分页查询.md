# 物料库存菜单分页查询接口文档

## 1. 接口概述

接口名称：物料库存菜单分页查询

接口方法：getMaterialStockMenuPageList

请求方式：POST

请求路径：/open/api/saas/erp/inventory/stock/material/menuPage

接口描述：分页查询物料库存菜单，保留左侧物料类别分组筛选和关键字查询能力
