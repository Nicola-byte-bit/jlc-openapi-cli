# findProductPrice

**域名:** https://open-api.jlc.com

**接口地址:** /lcsc/openapi/product/get/price/by/code

**请求方式:** POST **请求数据类型:** application/json **响应数据类型:** */* **接口描述:** 查询商品价格

**请求示例:**

<mark>{</mark> "productCodeList": ["C1001","C1002"]

}

## 请求参数:

|**参数名称**|**参数说明**|**请求**|**是否**|**数据类型**|**schema**|
|---|---|---|---|---|---|
|||**类型**|**必须**|||
|openPubPriceReqVO|OpenPubPriceReqVO|body|true|OpenPubPriceReqVO|OpenPubPriceReqVO|
|productCodeList|商品编号集合||false|array|string|

## 响应状态:

|**状态码**|**说明**|**schema**|
|---|---|---|
|200|OK|HttpOpenapiResultListOpenPubPriceVO|

## 响应参数:

|**参数名称**|**参数说明**|**类型**|**schema**|
|---|---|---|---|
|code|状态码|integer(int32)|integer(int32)|
|message|消息内容|string||
|data|返回内容|array|OpenPubPriceVO|
|productId|商品ID|integer(int32)||
|productCode|商品编号|string||
|priceList|价格信息|array|OpenPubProductPricesVO|
|startStep|起始阶梯|integer||
|originPrice|原价|number||
|discountedPrice|折扣价|number||
|successful||boolean||
