# findAllStock

**域名:** https://open-api.jlc.com

**接口地址:** /lcsc/openapi/stock/select/all/stock/by/id

**请求方式:** POST

**请求数据类型:** application/json **响应数据类型:** */*

**接口描述:** 查询 **商品** 库存

**请求示例:**

{ "productCodeList": ["c1001", "c1002"] }

## 请求参数:

|**参数名称**|**参数说明**|**请求类型**|**是否必须**|**数据类型**|**schema**|
|---|---|---|---|---|---|
|allStockReqVO|AllStockReqVO|body|true|AllStockReqVO|AllStockReqVO|
|productCodeList|商品编号集合||false|array|string|

## 响应状态:

|**状态码**|**说明**|**schema**|
|---|---|---|
|200|OK|HttpOpenapiResultListAllStockVO|

## 响应参数:

|**参数名称**|**参数说明**|**类型**|**schema**|
|---|---|---|---|
|code|状态码|integer(int32)|integer(int32)|
|message|消息内容|string||
|data|返回内容|array|AllStockVO|
|productId|商品ID|integer(int32)||
|productCode|商品编号|string||
|szValidNumber|深圳（珠海）可用库存(库<br>存数量-现货占用)|integer(int32)||
|jsValidNumber|江苏可用库存(库存数量-<br>现货占用)|integer(int32)||
|successful||boolean||

## 响应示例:

{ "code": 0,

"message": "", "data": [ { "productId": 0, "productCode": "", "szvalidNumber": 0, "jsvalidNumber": 0 } ], "successful": true }
