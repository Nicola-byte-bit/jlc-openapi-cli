# batchSearchModel

**域名:** https://open-api.jlc.com **接口地址:** /lcsc/openapi/bom/search

**请求方式:** POST

**请求数据类型:** application/json **响应数据类型:** */* **接口描述:** 型号批量搜索

**请求示例:** { "querys":["smt", "未知"] }

**请求参数:**

|**参数名称**|**参数说明**|**请求类型**|**是否必须**|**数据类型**|**schema**|

|querys|型号列表||true|list|string|
