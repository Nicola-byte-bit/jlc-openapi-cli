# 立创商城-订单列表查询

**域名:** https://open-api.jlc.com

**接口地址:** /lcsc/openapi/order/list

**请求方式:** POST

**请求数据类型:** application/json

**响应数据类型:** */*

**接口描述:** 订单列表查询

## 请求示例:

<mark>{</mark>

"currPage": 1, "pageSize": 10, "startCreateTime": "2024-10-19 00:00:00", "endCreateTime": "2024-12-19 00:00:00"

}

## <u>请求参数:</u>

|**参数名称**|**参数说明**|**请求类型**|**是否必须**|**数据类型**|**schema**|
|---|---|---|---|---|---|
|orderListPageReqVO|订单列表分页<br>查询参数|body|true|OrderListPageReqVO|OrderListPageReqVO|
|currPage|当前页,默认1||false|integer(int32)||
|pageSize|数据条数，默<br>认10条，每<br>页最多100 条||false|integer(int32)||
|startCreateTime|起始创建时间<br>yyyy-MM-dd<br>HH:mm:ss||true|string(date-time)||
|endCreateTime|截止创建时间<br>yyyy-MM-dd<br>HH:mm:ss||true|string(date-time)||

**<u>响应状态:</u>**

|**状态码**|**说明**|**schema**|
|---|---|---|
|200|OK|HttpOpenapiResultPageVOListOrderInfoRespVO|
