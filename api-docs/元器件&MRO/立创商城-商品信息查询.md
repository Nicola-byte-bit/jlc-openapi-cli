# findProductInfoByKeyWord

**域名:** https://open-api.jlc.com

**接口地址:** /lcsc/openapi/product/search/global

**请求方式:** POST

**请求数据类型:** application/json **响应数据类型:** */*

**接口描述:** 查询商品信息

**请求示例:** { "keyword": "" }

**请求参数:**

|**参数名称**|**参数说明**|**请求**<br>**类**<br>**型**|**是否**<br>**必**<br>**须**|**数据类型**|**schema**|
|---|---|---|---|---|---|
|openPubProductReq<br>VO|OpenPubProductReq<br>VO|bod<br>y|true|OpenPubProductReq<br>VO|OpenPubProductReq<br>VO|
|keyword|搜索关键字||fals<br>e|string||
