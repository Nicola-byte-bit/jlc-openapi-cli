# 查询元器件信息

## 基本信息

请求方式：POST

请求路径：/smtOpenApi/smtComponent/selectComponentInfoByCodes 请求参数

### **Header** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|是|签名认证生成认证信息|
|Content-Type|string|是|请设置为application/json|
|Accept|string|是|请设置为application/json|

### **Body** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|componentCodeList|List<string>|是|元器件编号List|

## 响应参数 **data[]**

|名称|类型|描述|
|---|---|---|
|componentId|int|元件ID|
|componentCode|String|元件编号|
|componentName|String|元件名称|
|componentType|String|元件类别|
|componentModel|String|元件型号|
|componentSpecification|String|封装规格|
|componentBrand|String|品牌产地|
|encapsulationNumber|int|封装数量|
|stockNum|int|库存数量|
|paramTextAll|String|描述|
|smtComponentPriceInfoVOList|List<SelectComponentPriceResultData>|阶梯售价|

## <u>响应参数</u> List<SelectComponentPriceResultData>

|名称|类型|描述|
|---|---|---|
|componentId|int|元件ID|
|componentCode|String|元件编号|
|startNumber|int|元件起始数量|
|endNumber|int|元件结束数量|
|productPrice|BigDecimal|元件单价|

{

> "componentCodeList":[“C1”,”C2”,”C3”]}
