# 保存邮寄信息

## 基本信息

请求方式：POST

请求路径：/smtOpenApi/componentMail/saveMailInfo 请求参数

### **Header** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|是|签名认证生成认证信息|
|Content-Type|string|是|请设置为application/json|
|Accept|string|是|请设置为application/json|

### **Body** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|expressNumber|string|是|快递单号|
|senderName|string|是|邮寄人名称|
|senderPhone|string|是|邮寄人电话|
|customerMailPackageKeyId|string|是|包裹Id|

## 响应参数 **data[]**

|名称|类型|描述|
|---|---|---|

## 请求示例

{

"expressNumber":”SF123456”,

“senderName”:”名称”,

“senderPhone”:”15912345678”,

“customerMailPackageKeyId”:”45645445”

}

## 响应示例

{"success": **true** ,

"code": 200,

"message": **null** ,

"data": [] }

|错误码|描述|
|---|---|
