# 保存邮寄包裹信息

## 基本信息

请求方式：POST

请求路径：/smtOpenApi/componentMail/saveMailPackage 请求参数

### **Header** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|是|签名认证生成认证信息|
|Content-Type|string|是|请设置为application/json|
|Accept|string|是|请设置为application/json|

### **Body** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|packageName|string|是|包裹名称|
|savePackageMailDetailRequestVOS|List|是|需要邮寄的信息|

savePackageMailDetailRequestVOS 信息

|名称|类型|必须|描述|
|---|---|---|---|
|accessId|string|是|待邮寄元器件AccessId|
|customerMailNumber|int|是|客户邮寄数量|

## 响应参数 **data[]**

名称 类型 描述 请求示例 {

- "packageName":”未命名的包裹”,

"savePackageMailDetailRequestVOS":[

{

- “accessId”:”544sd5f5s”,

- “customerMailNumber”:10

} ] }

## 响应示例

{"success": **true** , "code": 200, "message": **null** , "data": [] }

## <u>错误码</u>

错误码 描述

200 请求成功 500 请求失败
