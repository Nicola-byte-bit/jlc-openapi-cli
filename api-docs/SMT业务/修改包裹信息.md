# 修改包裹信息

## 基本信息

请求方式：POST

请求路径：/smtOpenApi/componentMail/updateMailPackageInfo 请求参数

### **Header** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|是|签名认证生成认证信息|
|Content-Type|string|是|请设置为application/json|
|Accept|string|是|请设置为application/json|

### **Body** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|customerMailPackageKeyId|string|是|邮寄包裹主键KeyId|
|packageName|string|是|包裹名称|

## 响应参数 **data[]**

|名称|类型<br>描述|
|---|---|

## 请求示例

{

- "customerMailPackageKeyId":”sdfds546456”,

- "packageName":”包裹 123”

}

## 响应示例

{"success": **true** ,

"code": 200,

"message": **null** ,

"data": []

}

## <u>错误码</u>

|错误码|描述|
|---|---|
|200|请求成功|
|500|请求失败|
