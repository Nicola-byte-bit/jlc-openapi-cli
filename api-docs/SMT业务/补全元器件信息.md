# 补全元器件信息

## 基本信息

请求方式：POST

请求路径：/smtOpenApi/componentMail/applyComponent 请求参数

### **Header** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|是|签名认证生成认证信息|
|Content-Type|string|是|请设置为application/json|
|Accept|string|是|请设置为application/json|

### **Body** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|componentCodeTemp|string|是|临时D 编号|
|dataAddressUrl|string|是|数据手册超链接|
|componentMailAccessId|string|是|邮寄明细accessId|
|componentModel|string|是|元器件型号|
|componentSpecification|string|是|元器件封装规格|
|packageCode|string|否|包装方式{编带：biandai，托盘：tuopan，<br>袋装：daizhuang，管装：guanzhuang，<br>盒装：hezhuang，卷：juan，本：ben}|
|predictUseTime|int|否|预计使用时间（1：一天内, 2：三天后, 3：<br>一周内, 4：一周后）|
|jlcEdaLibrary|string|否|嘉立创EDA 库|

## 响应参数 **data[]**

|名称|类型|描述|
|---|---|---|

## 请求示例

{

- "componentCodeTemp":”D20231204000123”,

- "dataAddressUrl":”https://ava/ce.pdf”,

- "componentMailAccessId":”sdfsdf”,

- "componentModel":”4D”,

- "componentSpecification":”0402”,

- "packageCode":”biandai”,

- "predictUseTime":2,

- "jlcEdaLibrary":”CS_0402”

}

## 响应示例

- {"success": **true** ,

- "code": 200,

"message": **null** , "data": [] } <u>错误码</u> 错误码 描述 200 请求成功 500 请求失败
