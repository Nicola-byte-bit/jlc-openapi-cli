# 查询待邮寄包裹详细信息

请求方式：POST

请求路径：/smtOpenApi/componentMail/selectCustomerPackageDetail 请求参数

### **Header** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|是|签名认证生成认证信息|
|Content-Type|string|是|请设置为application/json|
|Accept|string|是|请设置为application/json|

### **Body** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|customerMailPackageKeyId|string|是|包裹ID|

## 响应参数 **data[]**

|名称|类型|描述|
|---|---|---|
|customerMailPackageDetailKeyId|string|邮寄包裹详情Id|
|customerComponentCode|string|客户元器件编号|
|componentId|int|元器件id|
|componentCode|string|元器件编号|
|componentModel|string|元件型号|
|componentName|string|元器件名称|
|componentSpecification|string|封装规格|
|componentType|string|元器件类别|
|currentStockNumber|int|当时库存数量|
|waitMailComponentNumber|int|手动添加数量|
|customerMailNumber|int|邮寄数量|
|labelPasteFlag|Boolean|是否已贴装元器件编号|
|smtOrderCode|string|关联SMT 订单编号|
|pcbOrderFilename|string|PCB 文件名称|
|remark|string|邮寄说明|
|unitPrice|BigDecimal|单价|
|valuableFlag|Boolean|是否贵重器件|
