# 添加至待邮寄包裹

## 基本信息

请求方式：POST

请求路径：/smtOpenApi/componentMail/addCustomerPackageDetail 请求参数

### **Header** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|是|签名认证生成认证信息|
|Content-Type|string|是|请设置为application/json|
|Accept|string|是|请设置为application/json|

### **Body** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|componentMailAccessIdList|List<String>|是|待邮寄元器件的AccessId|
|customerMailPackageKeyId|String|是|邮寄包裹ID|

## 响应参数 **data[]**

|名称|类型|描述|
|---|---|---|
