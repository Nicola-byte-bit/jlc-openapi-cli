# 查询元器件待邮寄包裹

### 请求方式： POST

请求路径：/smtOpenApi/componentMail/selectWaitPackageList 请求参数

**Header 参数**

|**名称**|**类型**|**必须**|**描述**|
|---|---|---|---|
|Authorization|string|是|签名认证 生成认证信息|
|Content-Type|string|是|请设置为application/json|
|Accept|string|是|请设置为application/json|

**Body 参数 名称 类型 必须 描述**

## 响应参数 data[]

|**名称**|**类型**|**描述**|
|---|---|---|
|customerMailPackageKeyId|string|邮寄包裹Id|
|packageName|string|包裹名称|
|packageCreateTime|date|包裹创建时间|
|componentCountNumber|int|包裹元器件种类数|
