# 查询元器件待邮寄信息

## 基本信息

请求方式：POST

请求路径：/smtOpenApi/componentMail/selectWaitMailList 请求参数

### **Header** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|是|签名认证生成认证信息|
|Content-Type|string|是|请设置为application/json|
|Accept|string|是|请设置为application/json|

### **Body** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|keywords|string|否|关键字|
|mailSource|int|否|邮寄来源（1：提前邮寄，2：smt 邮寄）|

## 响应参数 **data[]**

|名称|类型|描述|
|---|---|---|
|groupCode|string|分组编号|
|groupId|string|分组id|
|mailSource|int|邮寄来源（1：提前邮寄，2：smt 邮寄）|
|waitMailInfoResponseVOList|list|邮寄元器件详情|
|waitMailInfoResponseVOList|参数[]||
|componentMailAccessId|string|邮寄业务accessId|
|componentNumber|int|元器件数量|
|stockNum|int|库存数量|
|leastPatchNumber|int|最小贴装数量|
|customerComponentCode|string|客户元器件编号|
|needMailNumber|int|需要邮寄的数量|
|remark|string|备注|
|componentCodeTemp|string|临时编号|
|smtOrderCode|string|smt 订单编号|
|pcbOrderFilename|string|PCB 文件名称|
|mailSource|int|邮寄来源，{1：提前邮寄，2：SMT 邮寄}|
|smtOrderUseNum|int|smt 订单使用数量|
|mailComponentFlag|Boolean|是否可邮寄|
|请求示例|||

{

"keywords":”关键字”,

“mailSource”:1

}
