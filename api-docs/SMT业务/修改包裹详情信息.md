# 修改包裹详情信息

## 基本信息

请求方式：POST

请求路径：/smtOpenApi/componentMail/updateMailPackageDetail 请求参数

### **Header** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|是|签名认证生成认证信息|
|Content-Type|string|是|请设置为application/json|
|Accept|string|是|请设置为application/json|

### **Body** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|customerMailPackageDetailKeyId|string|是|邮寄包裹详情KeyId|
|customerMailNumber|int|是|邮寄数量|
|unitPrice|bigDecimal|是|单价|
|valuableFlag|boolean|是|是否贵重器件|

备注 ：valuableFlag 为true 时，价格才会更新

## 响应参数 **data[]**

|名称|类型<br>描述|
|---|---|

## 请求示例

{

"customerMailPackageDetailKeyId":”sdfds546456”,

"customerMailNumber":10,

“unitPrice”:”12.02”,

“valuableFlag”:false

}

## 响应示例

{"success": **true** , "code": 200,

"message": **null** ,

"data": [] }

## <u>错误码</u>

|错误码|描述|
|---|---|
|200|请求成功|
|500|请求失败|
