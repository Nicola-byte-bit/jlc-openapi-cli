# 添加元器件邮寄

## 基本信息

<mark>请求方式：POST</mark>

<mark>请求路径：</mark> /smtOpenApi/order/addComponentMail <mark>请求参数</mark>

### **<mark>Header</mark>** <mark>参数</mark>

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|是|签名认证生成认证信息|
|Content-Type|string|是|请设置为application/json|
|Accept|string|是|请设置为application/json|

### **<mark>Body</mark>** <mark>参数</mark>

|名称|类型|必须|描述|
|---|---|---|---|
|comment|String|必须|型号|
|footprint|String|必须|封装|
|mailNumber|Integer|必须|邮寄数量|
|customerCode|String|必须|客户编号|

## 请求示例

{

"comment":"1206W4J0103T5E",

"footprint":"1206", "mailNumber":5, "customerCode":"00012A"

}

## 响应示例

{

"success": **true** , "code": 200, "message": **null** ,

"data": **null**

}
