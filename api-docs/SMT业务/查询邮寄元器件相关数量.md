# 查询邮寄元器件相关数量

## 基本信息

请求方式：POST

请求路径：/smtOpenApi/componentMail/selectMailComponentNumberInfo 请求参数

### **Header** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|是|签名认证生成认证信息|
|Content-Type|string|是|请设置为application/json|
|Accept|string|是|请设置为application/json|

### **Body** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|componentCodeList|List<string>|是|元器件编号List|

## 响应参数 **data[]**

|名称|类型|描述|
|---|---|---|
|componentCode|string|元器件编号|
|currentStockNumber|int|当前库存数量|
|leastPatchNumber|int|最小邮寄数量|
|unitPrice|bigDecimal|单价|

## 请求示例

{

"componentCodeList":[

“C1”,

”C2”,

”C3”

] }

## 响应示例

{"success": **true** ,

"code": 200, "message": **null** ,

"data": [ {

"componentCode": "C1",

"currentStockNumber":100,

- "leastPatchNumber": 1,

- "unitPrice": 3.21,

}, {

- "componentCode": "C2",

- "currentStockNumber":10,

- "leastPatchNumber": 3,

- "unitPrice": 5.21,

}

]

}

## <u>错误码</u>

错误码 描述 200 请求成功 500 请求失败
