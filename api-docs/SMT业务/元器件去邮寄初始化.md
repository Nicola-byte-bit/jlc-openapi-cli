# 去邮寄初始化信息 基本信息

请求方式：POST

请求路径：/smtOpenApi/componentMail/toMailInit 请求参数

## **Header** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|是|签名认证生成认证信息|
|Content-Type|string|是|请设置为application/json|
|Accept|string|是|请设置为application/json|

## **Body** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|customerMailPackageKeyId|string|是|待邮寄包裹ID|
|labelPasteFlag|Boolean|是|是否有贴装元器件编号|
|valuableFlag|Boolean|是|是否贵重器件|
|continueMailFlag|Boolean|是|是否继续邮寄|

# 响应参数 **data[]**

|名称|类型|描述|
|---|---|---|
|customerCode|string|客户编号|
|packageCode|string|包裹编号|
|encryptPackageCode|string|加密包裹编号|
|expressNumber|string|快递单号|
|expressCompany|string|快递公司|
|waitMailComponentList|list|包裹元器件明细|
|waitMailComponentList|参数[]||

|componentMailAccessId|string|邮寄器件accessId|
|componentNumber|int|元器件数量|
|stockNum|int|库存数量|
|leastPatchNumber|int|最小贴装数量|
|customerComponentCode|string|客户元器件编号|
|needMailNumber|int|需要邮寄的数量|
|remark|string|备注|
|componentCodeTemp|string|临时编号|
|smtOrderCode|string|smt 订单编号|
|pcbOrderFilename|string|PCB 文件名称|
|mailSource|int|邮寄来源，{1：提前邮寄，2：SMT 邮寄}|
|smtOrderUseNum|int|smt 订单使用数量|
|labelPasteFlag|Boolean|是否已贴装元器件编号|
