# PCB 查询订单接口

## 基本信息

请求方式：POST 请求路径：/pcb/order/get

## 请求参数

**Header** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|是|签名认证生成认证信息|
|Content-Type|string|是|请设置为application/json|
|Accept|string|是|请设置为application/json|

### **Body** 参数

|名称|类型|必须|示例值|描述|
|---|---|---|---|---|
|serialCode|string|是|1d3lcy_0005|板子序列码|

|stencilPly|number|板厚|

|stencilNumber|integer|拼版个数|
|adornColor|string|阻焊颜色|
