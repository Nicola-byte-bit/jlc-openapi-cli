# PCB 查询订单文件下载接口

## 基本信息

请求方式：POST

请求路径：/pcb/order/getOrderDownloadFile

## 请求参数

**Header** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|是|签名认证生成认证信息|
|Content-Type|string|是|请设置为application/json|
|Accept|string|是|请设置为application/json|

### **Body** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|customerOrderId|integer|是|订单编号|
|orderType|string|是|订单类别，样板：examples 小批量：batch|
|fileType|integer|是|文件类型<br>1:工程文件|
|downloadReason|integer|是|下载原因：1、备份需要2、转其他板厂做<br>单3、转其他钢网厂做钢网4、检查资料<br>的准确性5、其他情况|

## 响应参数

|名称|类型|描述|
|---|---|---|
|fileName|stirng|文件名称|
|downloadUrl|string|文件下载链接|

- "fileType":1,
