# PCB 查询订单生产进度接口

## 基本信息

请求方式：POST

请求路径：/pcb/order/progress/get

## 请求参数

**Header** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|是|签名认证生成认证信息|
|Content-Type|string|是|请设置为application/json|
|Accept|string|是|请设置为application/json|

### **Body** 参数

|名称|类型|必须|示例值|描述|
|---|---|---|---|---|
|customerOrderId|integer|是|17618739|订单编号|
|orderType|string|是|examples|订单类别，样板：examples<br>小批量：batch|

## 响应参数

|名称|类型|描述|
|---|---|---|
|allTechInfoList|object|所有生产工艺信息|
|currentTech|string|当前工艺|
|orderStatus|string|订单状态wip_status_test 进入测试环节delivery_w<br>ait_print 进入打印送货单环节express_wait_print 进<br>入打印快递单环节express_complete_print 进入扫<br>描发货环节complete_send 订单已发货canceled<br>订单已取消confirmed 订单下单完成waitcarrier 已<br>提交厂方生产|
|pcbFile|string|文件名|
|orderDate|string|下单日期|
|achieveTime|string|交货时间|
|produceId|string|生产订单id|
|produceCode|string|生产订单编号|

|expressNo|string|快递号|
|expressCompany|string|快递公司|

## 所有生产工艺信息响应结果

|名称|类型|描述|
|---|---|---|
|techName|stirng|工艺名称|
|techBeginTime|string|工艺开始时间|
