# PCB 查询订单实物图接口

## 基本信息

请求方式：POST

请求路径：/pcb/order/getOrderPhysicalPicture

## 请求参数

**Header** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|是|签名认证生成认证信息|
|Content-Type|string|是|请设置为application/json|
|Accept|string|是|请设置为application/json|

### **Body** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|customerOrderId|integer|是|订单编号|
|orderType|string|是|订单类别，样板：examples 小批量：batch|

## 响应参数

|名称|类型|描述|
|---|---|---|
|physicalPictureList|object|实物图图片详情|

## 实物图详情响应结果

|名称|类型|描述|
|---|---|---|
|pictureDownloadUrl|stirng|图片获取链接(有效期:2天)|
|pictureSite|integer|图片方位(0:顶层,1:底层)|
|pictureType|integer|图片类型(0:缩略, 1:高清)|
