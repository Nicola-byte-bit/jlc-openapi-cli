# PCB 查询在线价格接口

## 基本信息

请求方式：POST

请求路径：/pcb/order/getOrderPriceDetails

## 请求参数

**Header** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|是|签名认证生成认证信息|
|Content-Type|string|是|请设置为application/json|
|Accept|string|是|请设置为application/json|

### **Body** 参数

|名称|类型|必须|示例值|描述|
|---|---|---|---|---|
|customerOrderId|integer|是|17618739|订单编号|
