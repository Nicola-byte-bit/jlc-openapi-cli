# PCB 查询订单物流轨迹接口

## 基本信息

请求方式：POST

请求路径：/pcb/order/getExpressSchedule

## 请求参数

**Header** 参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|是|签名认证生成认证信息|
|Content-Type|string|是|请设置为application/json|
|Accept|string|是|请设置为application/json|

### **Body** 参数

|名称|类型|必须|示例值|描述|
|---|---|---|---|---|
|customerOrderId|integer|是|17618739|订单编号|
|orderType|string|是|examples|订单类别，样板：examples<br>小批量：batch|

## 响应参数

|名称|类型|描述|
|---|---|---|
|expressScheduleFrom|string|快递进度来源|
|expressNo|string|快递单号|
|expressDetailList|object|物流轨迹详情|

## 物流轨迹详情响应结果

|名称|类型|描述|
|---|---|---|
|acceptAddress|stirng|到件地址|
|acceptTime|string|到件时间|
