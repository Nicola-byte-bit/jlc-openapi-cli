# 基本信息

请求方式：GET

请求路径：/3dp-open/order/getAllEnableMaterialInfo

# 请求参数

# Header 参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|必须|签名认证生成认证信息|
|Content-Type|string|必须|设置为application/json|
|Accept|string|必须|设置为application/json|

# 响应参数

|名称|类型|描述|
|---|---|---|
|data|List<Material>|材料信息|

# Material 材料信息参数

|名称|类型|描述|
|---|---|---|
|materialTypeId|Long|材料类型id|
|materialType|String|材料类型|
|materialAccessId|String|材料业务id|
|materialName|String|材料名称|
|materialDeliveryVOList|List<MaterialDeliveryVO>|材料交期|
|materialContrastColorVoList|List<MaterialContrastColorVo>|材料对应颜色属性|

# MaterialDelivery 材料交期参数

|名称|类型|描述|
|---|---|---|
|materialDeliveryAccessId|String|材料交期业务id|
|deliveryType|Integer|交期类型(1:加急交期,2:正常交期,3:其他交期)|
|deliveryDate|String|交期(h)|

MaterialContrastColor 材料对应颜色属性参数

|名称|类型|描述|
|---|---|---|
|contrastColorAccessId|String|材料对应颜色accessId|
|colorName|String|材料对应颜色名称|
