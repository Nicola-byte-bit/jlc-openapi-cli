# 基本信息

请求方式：POST

请求路径：/3dp-open/order/checkMaterialSizeLimit

# 请求参数

# Header 参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|必须|签名认证生成认证信息|
|Content-Type|string|必须|设置为application/json|
|Accept|string|必须|设置为application/json|

# body 参数

|名称|类型|必须|描述|
|---|---|---|---|
|requests|List<CheckMaterialSizeParam>|必须|材料尺寸限制校验请求参数|

# CheckMaterialSizeRequest 材料尺寸限制校验请求参数参数

|名称|类型|必须|描述|
|---|---|---|---|
|modelAccessId|String|必须|模型业务id|
|materialTypeId|Long|必须|材料类型id|
|materialAccessId|String|必须|材料业务id|
|deliveryType|Integer|必须|交期类型|

# 响应参数

|名称|类型|描述|
|---|---|---|
|response|List<CheckMaterialSizeResponse>|材料尺寸限制校验响应|

# CheckMaterialSizeResponse 材料尺寸限制校验响应参数

|名称|类型|描述|
|---|---|---|
|modelAccessId|String|模型业务id|
|materialAccessId|String|材料业务id|
|checkFlag|Boolean|是否通过校验(false 没通过校验，true 通过校验)|
|checkResult|Integer|校验结果0：校验通过1:材料类型尺寸不符合2：<br>材料尺寸不符合3：材料交期尺寸不符合4：其他<br>条件不符合|

# 请求示例

{

"checkMaterialSizeRequestList": [

{

"modelAccessId": "4b54f6ff629d4e3c9243f380b596d20d",

"materialTypeId": 1,

"materialAccessId": "8cb7d4f027d046758b956d946a55f044",

"deliveryType": 2

} ] }

"successful": true }
