# 14.查询可⽤快递

## 基本信息

请求⽅式：POST 请求路径：/3dp-open/order/getAvailableExpress

## 请求参数

## Header参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|必须|签名认证 ⽣成认证信息|
|Content-Type|string|必须|设置为application/json|
|Accept|string|必须|设置为application/json|

## body参数

|名称|类型|必须|描述|
|---|---|---|---|
|modelPriceParamList|List|必须|商品集合|
|expressReceiverInfo|ExpressReceiverInfo|必须|快递收货⼈信息|

## DeliveryPriceParam 计算价格参数 参数

|名称|类型|必须|描述|
|---|---|---|---|
|materialAccessId|String|必须|材料业务id|
|contrastColorAccessId|String|必须|材料对应颜⾊accessId|
|materialDeliveryAccessId|String|必须|交期业务id|
|modelAccessId|String|必须|模型业务id|
|modelCount|Integer|必须|商品数量|
|surfaceTreatmentList|List|必须|表⾯处理信息|

SurfaceTreatment提交订单表处 参数

|名称|类型|必须|描述|
|---|---|---|---|
|craftAccessId|String|必须|⼯艺业务id|
|craftCode|String|必须|⼯艺编码|
|craftName|String|必须|⼯艺名称|
|craftOptionAccessId|String|必须|表⾯选项业务id|
|parameterName|String|必须|属性名称|
|craftAttributeAccessId|String|必须|⼯艺属性业务id|
|parameterCode|String|必须|属性编码|
|parameterValue|String|必须|属性值|
|fatherAttributeAccessId|String|⾮必<br>须|⽗⼯艺属性业务id|
|enterType|Integer|必须|录⼊⽅式0:默认1:⽤⼾上传2:⽤⼾输⼊|
|customerCraft|String|必须|客⼾输⼊ 字段，enterType=2时,作为<br>镶嵌螺⺟数量|
|fileSystemAccessId|String|⾮必<br>须|镶嵌螺⺟⽂件id|

## ExpressReceiverInfo 快递收货⼈信息 参数

|名称|类型|必须|描述|
|---|---|---|---|
|province|String|必须|收货⼈省份|
|city|String|必须|收货⼈城市|
|area|String|必须|收货⼈地区|
|districtName|String|必须|收货⼈四级地址|
|receiveAddress|String|必须|收货⼈详细地址|

## 响应参数

|名称<br>类型|描述|
|---|---|

查询可⽤快递返回结果

data

GetAvailableExpressResult

## GetAvailableExpressResult 查询可⽤快递返回结果 参数

|名称|类型|描述|
|---|---|---|
|receiverInfo|ReceiverInfo|收货⼈信息（补上收货⼈详细地址、姓名、电话<br>后，可⽤于作为后续提交订单的地址参数）|
|expressDetailList|List|快递详情|

## ReceiverInfo 收货信息 参数

|名称|类型|描述|
|---|---|---|
|province|String|收货⼈省份|
|provinceCode|String|收货⼈省份编码|
|city|String|收货⼈城市|
|cityCode|String|收货⼈城市编码|
|area|String|收货⼈地区|
|areaCode|String|收货⼈地区编码|
|districtName|String|收货⼈四级地址|
|districtCode|String|四级地址编码|
|receiveAddress|String|收货⼈详细地址（返回空）|
|receiverName|String|收货⼈姓名（返回空）|
|receiverPhone|String|收货⼈电话（返回空）|

注：地址编码为全国⾏政区划代码，参考

https://www.mca.gov.cn/mzsj/xzqh/2023/202301xzqh.html ExpressDetail 快递详情 参数

|名称|类型|描述|
|---|---|---|
|expressType|String|快递公司code|
|expressName|String|快递名称|

|carriageFee|BigDecimal|预估运费|
|minDeliveryDay|Integer|最⼩时效（单位天）|
|maxDeliveryDay|Integer|最⼤时效（单位天）|
