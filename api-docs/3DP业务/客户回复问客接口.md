# 客⼾回复问客接⼝

请求⽅式：POST

请求路径：/3dp-open/ask/replyOPAsk

## 请求参数

## Header参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|必须|签名认证 ⽣成认证信息|
|Content-Type|string|必须|设置为application/json|
|Accept|string|必须|设置为application/json|

## body参数

|名称|类型|必须|描述|
|---|---|---|---|
|askAccessId|String|必须|问客业务id|
|content|String|必须|问客内容|

## 响应参数

|名称|类型|描述|
|---|---|---|
|data|⽆|⽆返回值|
