# 查询快递进度接⼝

查询快递进度接⼝ 基本信息

请求⽅式：POST

请求路径：/3dp-open/order/getExpressDetail

## 请求参数

## Header参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|必须|签名认证 ⽣成认证信息|
|Content-Type|string|必须|设置为application/json|
|Accept|string|必须|设置为application/json|

## body参数

|名称|类型|必须|描述|
|---|---|---|---|
|orderAccessId|String|必须|订单accessId|

## 响应参数

|名称|类型|描述|
|---|---|---|
|data|SelectExpressResponseVo|快递详情信息|

## SelectExpressResponseVo

|名称|类型|描述|
|---|---|---|
|expressNo|String|快递号|
|expressName|String|快递名称|
|signFlag|Boolean|是否已签收|

detailsList List< ExpressProcessDetailVO>

详情

## ExpressProcessDetailVO

|名称|类型|描述|
|---|---|---|
|acceptAddress|String|详情内容|
|acceptTime|Date|详情时间|
|status|String|状态|
