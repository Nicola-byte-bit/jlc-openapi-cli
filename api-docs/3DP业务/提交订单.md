# 提交订单接口

## 更改记录

|**更改时**<br>**间**|**更改内容**|
|---|---|
|2026-|OPDeliveryPriceParam里 新增了 customerPersonalizeCode 客户自定义编|
|08-13|号|
|2026-|OPDeliveryPriceParam里 新增了 productionBaseCode 自选生产基地|
|09-16|code、productionBaseMismatchHandleType 生产基地不匹配处理方式|

## 提交订单接口 基本信息

**请求方式** ：POST

**请求路径** ：/3dp-open/order/submitOrder

## 请求参数

## Header参数

|**名称**|**类型**|**必须**|**描述**|
|---|---|---|---|
|Authorization|string|必须|签名认证 生成认证信息|
|Content-Type|string|必须|设置为 application/json|
|Accept|string|必须|设置为 application/json|

## body参数

|**名称**|**类型**|**必**<br>**须**|**描述**|
|---|---|---|---|
|deliveryType|Integer|必<br>须|交期类型|
|modelPriceParamList|List<<br>OPDeliveryPriceParam>|必<br>须|商品集合|
|orderLinkMan|OPLinkManInfo|必<br>须|联系人信息|
|receiverInfo|OPReceiverInfo|必<br>须|收货人信息|
|expressType|String|必<br>须|快递方式|
|dispatchType|Boolean|否|发货方式|

|**名称**|**类型**|**必**<br>**须**|**描述**|
|invoiceEmail|String|否|客户开票邮箱|
|invoiceMethod|Integer|否|开票方式 0随货，1累计|
|invoiceCategory|Integer|否|发票类型 0普通发票，1专<br>用发票|
|invoiceType|String|否|开票类型:<br>VAT_ELEC_INVOICE=增值<br>税电子普通发票，<br>SPECIAL_VAT_INVOICE=<br>增值税专用发票|
|receiptType|String|否|收据类型：NONE(不需要<br>送货单和收据),ELEC(电子送<br>货单和收据)，PAPER(纸质<br>送货单收据)；结算系统选<br>择后返回给订单系统|
|vatCompanyName|String|否|开票公司名称|
|confirmOrderType|String|否|AUTO：自动扣款并确认订<br>单<br>CUSTOMER_CONFIRM：<br>客户自己确认|
|remark|String|否|备注|
|packBoxType|Integer|否|打包盒类型 1：嘉立创盒子<br>2：空白盒子|

OPDeliveryPriceParam（商品集合 modelPriceParamList 元素）

|**名称**|**类型**|**必**<br>**须**|**描述**|
|---|---|---|---|
|materialAccessId|String|必<br>须|材料业务id|
|contrastColorAccessId|String|必<br>须|材料对应颜色accessId|
|materialDeliveryAccessId|String|必<br>须|交期业务id|
|modelAccessId|String|必<br>须|模型业务id|

|**名称**|**类型**|**必**<br>**须**|**描述**|
|modelCount|Integer|必<br>须|商品数量|
|customerPersonalizeCode|String|否|客户自定义编号 仅允<br>许字母、数字、短横线<br>(-)、下划线(_)及英文<br>句点(.)，不包含特殊符<br>号或空格|
|productionBaseCode|String|否|自选生产基地<br>code(sg_3dp:广东韶<br>关/js_3dp:江苏淮<br>安)，不传则按系统规<br>则自动分配|
|productionBaseMismatchHandleType|Integer|否|生产基地不匹配处理方<br>式 1-错误提示 2-系统<br>自动分配；<br>productionBaseCode<br>非空时必传|
|surfaceTreatmentList|List<<br>OPSurfaceTreatment>|否|表面处理信息|

## OPSurfaceTreatment（表面处理信息 surfaceTreatmentList 元素）

|**名称**|**类型**|**必须**|**描述**|
|---|---|---|---|
|craftAccessId|String|必须|工艺业务id|
|craftCode|String|必须|工艺编码|
|craftName|String|必须|工艺名称|
|craftOptionAccessId|String|必须|表面选项业务id|
|parameterName|String|必须|属性名称|
|craftAttributeAccessId|String|必须|工艺属性业务id|
|parameterCode|String|必须|属性编码|
|parameterValue|String|必须|属性值|
|fatherAttributeAccessId|String|否|父工艺属性业务id|
|enterType|Integer|否|录入方式|
|customerCraft|String|否|客户输入 字段|

|**名称**|**类型**|**必须**|**描述**|
|fileSystemAccessId|String|否|表处文件id|

## 注：表面处理列表本身可选；若提供表面处理，则上表必填字段需校验非空。

## OPLinkManInfo（联系人信息）

|**名称**|**类型**|**必须**|**描述**|
|---|---|---|---|
|orderLinkMan|String|否|下单联系人姓名|
|orderLinkPhone|String|否|下单联系人电话|
|techLinkMan|String|否|技术联系人姓名|
|techLinkPhone|String|否|技术联系人电话|

## OPReceiverInfo（收货人信息）

|**名称**|**类型**|**必须**|**描述**|
|---|---|---|---|
|province|String|否|收货人省份|
|provinceCode|String|否|收货人省份编码|
|city|String|否|收货人城市|
|cityCode|String|否|收货人城市编码|
|area|String|否|收货人地区|
|areaCode|String|否|收货人地区编码|
|districtName|String|否|四级地址|
|districtCode|String|否|四级地址编码|
|receiveAddress|String|否|收货人详细地址|
|receiverName|String|否|收货人姓名|
|receiverPhone|String|否|收货人电话|

## 响应参数

|**名称**|**类型**|**描述**|
|---|---|---|
|data|OPSubmitOrderResult|提交订单结果|

## OPSubmitOrderResult

|**名称**|**类型**|**描述**|
|---|---|---|
|submitOrderVOList|List< OPSubmitOrderVO>|订单详情|

## OPSubmitOrderVO

|**名称**|**类型**|**描述**|
|---|---|---|
|orderAccessId|String|订单业务id|
|orderCode|String|订单编号|
|payableAmount|BigDecimal|应付金额|
