# 7.获取模型价格

## 基本信息

请求⽅式：POST 请求路径：/3dp-open/order/getModelDeliveryPrice

## 请求参数

## Header参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|必须|签名认证 ⽣成认证信息|
|Content-Type|string|必须|设置为application/json|
|Accept|string|必须|设置为application/json|

## body参数

|名称|类型|必须|描述|
|---|---|---|---|
|modelPriceParamList|List<DeliveryPriceParam>|必须|计算材料价格参数|

## DeliveryPriceParam 计算价格参数 参数

|名称|类型|必<br>须|描述|
|---|---|---|---|
|materialAccessId|String|必<br>须|材料业务id|
|contrastColorAccessId|String|必<br>须|材料对应颜⾊<br>accessId|
|materialDeliveryAccessId|String|必<br>须|交期业务id|
|modelAccessId|String|必<br>须|模型业务id|

|modelCount|Integer|必<br>须|商品数量|
|surfaceTreatmentList|Listt<SurfaceTreatment>|必<br>须|表处参数|

## SurfaceTreatment 表处参数

|名称|类型|必须|描述|
|---|---|---|---|
|craftAccessId|String|必须|⼯艺业务id|
|craftCode|String|必须|⼯艺编码|
|craftName|String|必须|⼯艺名称|
|craftOptionAccessId|String|必须|表⾯选项业务id|
|parameterName|String|必须|属性名称|
|craftAttributeAccessId|String|必须|⼯艺属性业务id|
|parameterCode|String|必须|属性编码|
|parameterValue|String|必须|属性值|
|fatherAttributeAccessId|String|⾮必<br>须|⽗⼯艺属性业务id|
|enterType|Integer|必须|录⼊⽅式0:默认1:⽤⼾上传2:⽤⼾输⼊|
|customerCraft|String|必须|客⼾输⼊ 字段，enterType=2时,作为<br>镶嵌螺⺟数量|
|fileSystemAccessId|String|⾮必<br>须|镶嵌螺⺟⽂件id|

## 响应参数

|名称|类型|描述|
|---|---|---|
|data|List<ModelDeliveryPrice>|返回参数|

ModelDeliveryPrice 交期价格 参数

|名称|类型|描述|
|---|---|---|
|deliveryName|String|交期名称|
|deliveryType|Integer|交期类型|
|deliveryDate|Integer|交期时间|
|expectedDeliveryTimeStr|String|预计发货时间<br>（例如：2026-<br>06-14 12:00:00）|
|price|BigDecimal|交期价格|
|modelDeliveryPriceDetailList|List<ModelDeliveryPriceDetail>|模型价格详情|

## ModelDeliveryPriceDetail 模型价格详情 参数

|名称|类型|描述|
|---|---|---|
|modelAccessId|String|模型业务id|
|unitPrice|BigDecimal|单价|
