# 查询当前客⼾近半个⽉问客中的记录接⼝

查询当前客⼾近半个⽉问客中的记录接⼝ 基本信息

请求⽅式：POST

请求路径：/3dp-open/ask/getOPAskingAskList

## 请求参数

## Header参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|必须|签名认证 ⽣成认证信息|
|Content-Type|string|必须|设置为application/json|
|Accept|string|必须|设置为application/json|

## body参数

⽆（客⼾编码由服务端根据登录态⾃动获取）

## 响应参数

|名称|类型|描述|
|---|---|---|
|data|List< OPAskSimpleResponseVO>|问客中记录列表|

## OPAskSimpleResponseVO

|名称|类型|描述|
|---|---|---|
|askAccessId|String|问客详情accessId(⼀个订单有可能存在多个问客内容)|
|orderAccessId|String|订单accessId|
|orderCode|String|订单编号|
|fileName|String|⽂件名称|
|title|String|问客主题|

问客时间 格式：2026-01-01 00:00:00

askTime

String
