# 订单绑定发货接口

## 更改记录

|**更改时间**|**更改内容**|
|---|---|
|2026-10-|BindFailVO 新增 failCode 失败状态码字段，reason 失败原|
|22|因枚举更新|

## 订单绑定发货接口 基本信息

**请求方式** ：POST

**请求路径** ：/3dp-open/order/bindOPOrderBatch

## 请求参数

## Header参数

|**名称**|**类型**|**必须**|**描述**|
|---|---|---|---|
|Authorization|string|必须|签名认证 生成认证信息|
|Content-Type|string|必须|设置为 application/json|
|Accept|string|必须|设置为 application/json|

## body参数

|**名称**|**类型**|**必**<br>**须**|**描述**|
|---|---|---|---|
|orderCodes|List<<br>String>|必<br>须|需要绑定到同一发货批次的订单编号集<br>合（2~1000 个，不可重复，每个元素<br>长度 1~50）|

## 响应参数

|**名称**|**类型**|**描述**|
|---|---|---|
|data|BindOPOrderBatchResult|绑定发货结果|

## BindOPOrderBatchResult

|**名称**|**类型**|**描述**|
|---|---|---|
|successList|List< BindSuccessVO>|成功绑定订单列表|
|failList|List< BindFailVO>|失败订单列表（含失败原因）|

## BindSuccessVO（成功绑定订单 successList 元素）

|**名称**|**类型**|**描述**|
|---|---|---|
|orderCode|String|订单编号|
|batchCode|String|绑定后的批次号|
|deliveryDate|String|统一后的交期（取最长交期，格式 yyyy-MM-dd<br>HH:mm:ss）|

## BindFailVO（失败订单 failList 元素）

|**名称**|**类型**|**描述**|
|---|---|---|
|orderCode|String|订单编号|
|failCode|Integer|失败状态码（40001-外贸订单不支持绑定 /<br>40002-订单已部分发货不允许绑定 / 40003-订单<br>状态不允许绑定 / 40004-订单集货记录缺失 /<br>40005-订单已集货完成不允许绑定 / 40006-订单<br>暂无批次号）|
|reason|String|失败原因（外贸订单不支持绑定 / 订单已部分发货<br>不允许绑定 / 订单状态不允许绑定 / 订单集货记录<br>缺失 / 订单已集货完成不允许绑定 / 订单暂无批次<br>号）|

## 请求示例

- `{ "orderCodes": ["G26102000001", "G26102000002", "G26102000003"]`

- `}`

响应示例

`{ "code": 200, "message": null, "data": { "successList": [ { "orderCode": "G26102000001", "batchCode": "D-26102000001", "deliveryDate": "2026-10-27 20:00:00" }, { "orderCode": "G26102000002", "batchCode": "D-2026102000001", "deliveryDate": "2026-10-27 20:00:00" } ], "failList": [ { "orderCode": "G26102000003", "failCode": 40002, "reason": " 订单已部分发货不允许绑定 " } ] }, "successful": true }` **错误码 错误码描述** 200 请求成功 500 请求失败
