# 基本信息

请求方式：POST

请求路径：/3dp-open/order/getCraft

# 请求参数

# Header 参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|必须|签名认证生成认证信息|
|Content-Type|string|必须|设置为application/json|
|Accept|string|必须|设置为application/json|

# body 参数

|名称|类型|必须|描述|
|---|---|---|---|
|contrastColorAccessId|String|必须|材料对应颜色accessId|

# 响应参数

|名称|类型|描述|
|---|---|---|
|data|List<CraftInfo>|表面处理|

# CraftInfo 表面处理参数

|名称|类型|描述|
|---|---|---|
|craftName|String|工艺名称|
|craftCode|String|工艺编码|
|surfaceTreatmentList|List<List<SurfaceTreatment>>|每种表处只能选择一个List<br>作为参数提交订单参数|

SurfaceTreatment 提交订单表处参数

|名称|类型|描述|
|---|---|---|
|craftAccessId|String|工艺业务id|
|craftCode|String|工艺编码|
|craftName|String|工艺名称|
|craftOptionAccessId|String|表面选项业务id|
|parameterName|String|属性名称|
|craftAttributeAccessId|String|工艺属性业务id|
|parameterCode|String|属性编码|
|parameterValue|String|属性值|
|fatherAttributeAccessId|String|父工艺属性业务id|
|enterType|Integer|录入方式|
|customerCraft|String|客户输入字段，enterType=2时, 作为镶嵌螺<br>母数量|
|fileSystemAccessId|String|镶嵌螺母文件id|

"contrastColorAccessId": "727313ff8cdb4929943b723f9137e10"

}
