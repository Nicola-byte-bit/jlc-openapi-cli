# 获取⽣产进度信息接⼝（扁平版）

获取⽣产进度信息接⼝ 基本信息

请求⽅式：POST

请求路径：/3dp-open/order/getOPProcessProgress

## 请求参数

## Header参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|必须|签名认证 ⽣成认证信息|
|Content-Type|string|必须|设置为application/json|
|Accept|string|必须|设置为application/json|

## body参数

|名称|类型|必须|描述|
|---|---|---|---|
|orderAccessIdList|List< String>|否|订单accessId|
|itemAccessIdList|List< String>|否|商品accessId|

orderAccessIdList ,itemAccessIdList 必传其⼀，并且返回的值最多包含20条商品维度的数据

## 响应参数

|名称|类型|描述|
|---|---|---|
|data|List< OPProcessProgressVO>|⽣产进度信息列表|

OPProcessProgressVO

|名称|类型|描述|
|---|---|---|
|orderCode|String|订单编号|

|itemName|String|商品名称|
|orderAccessId|String|订单accessId|
|itemAccessId|String|商品accessId|
|productionOrderCode|String|⽣产单号|
|progressDetails|List< OPProcessProgressDetailVO>|⼯序进度明细|

## OPProcessProgressDetailVO

|名称|类型|描述|
|---|---|---|
|seq|Integer|序号|
|processName|String|⼯序名称|
|finishTime|Date|完成时间|
|status|Integer|状态1:未开始2:进⾏中3:已完成|

## 请求⽰例

- `{ "orderAccessIdList": [ "4d1454e71bd641e5866cb47d0fcab65c", "8a7b6c5d4e3f2011aabbccddeeff0011" ], "itemAccessIdList": [ "1a2b3c4d5e6f708192a3b4c5d6e7f809" ] }`

响应⽰例

`{ "code": 200, "message": null, "data": [ { "orderCode": "ORD20260909001", "itemName": "` 壳体 `.stl", "orderAccessId": "4d1454e71bd641e5866cb47d0fcab65c", "itemAccessId": "1a2b3c4d5e6f708192a3b4c5d6e7f809", "productionOrderCode": "SC20260909001", "progressDetails": [ { "seq": 1, "processName": "` 打印 `", "finishTime": 1783603646000, "status": 3 }, { "seq": 2, "processName": "` 表⾯处理 `", "finishTime": null, "status": 2 } ] } ], "successful": true }`

|错误码|错误码描述|
|---|---|
|200|请求成功|
|500|请求失败|
