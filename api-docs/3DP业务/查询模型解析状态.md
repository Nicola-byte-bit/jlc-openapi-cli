# 基本信息

请求方式：POST

请求路径：/3dp-open/order/queryModelAnalysisResult

# 请求参数

# Header 参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|必须|签名认证生成认证信息|
|Content-Type|string|必须|设置为application/json|
|Accept|string|必须|设置为application/json|

# body 参数

|名称|类型|必须|描述|
|---|---|---|---|
|modelAccessId|String|必须|模型业务id|

# 响应参数

|名称|类型|描述|
|---|---|---|
|data|Boolean|true解析完成，false解析未完成|

# 请求示例

- {

- "modelAccessId": "4d1454e71bd641e5866cb47d0fcab65c"

- }

# 响应示例

- {"code":200,"message":null,"data":true,"successful":true}

错误码 错误码描述 200 请求成功 500 请求失败
