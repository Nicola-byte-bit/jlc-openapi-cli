# 基本信息

请求方式：POST

请求路径：/3dp-open/order/getOrderProduceProgress

# 请求参数

# Header 参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|必须|签名认证生成认证信息|
|Content-Type|string|必须|设置为application/json|
|Accept|string|必须|设置为application/json|

# body 参数

|名称|类型|必须|描述|
|---|---|---|---|
|requestVO|OrderProduceProgressRequestVO|必须|请求参数|

# OrderProduceProgressRequestVO

|名称|类型|必须|描述|
|---|---|---|---|
|itemAccessId|String|必须|商品业务id|

# 响应参数

|名称|类型|描述|
|---|---|---|
|data|List<ItemProgressSplitVO>|响应参数|

# ItemProgressSplitVO

|名称|类型|描述|
|---|---|---|
|productionCode|String|生产订单编号|
|itemProgressVOS|List<OrderProduceProgressResponseVO>|生产进度集合|

OrderProduceProgressResponseVO 生产进度

|名称|类型|描述|
|---|---|---|
|serialNumber|Integer|序号|
|processName|String|进度名|
|processTime|Date|进度时间|
|processEnglishName|String|工序英文名称|
|processCode|String|工序编号|
