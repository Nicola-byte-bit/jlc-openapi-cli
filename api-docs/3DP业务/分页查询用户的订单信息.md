## 分⻚查询订单列表接⼝ 基本信息

请求⽅式：POST

请求路径：/3dp-open/order/getOrderInfoListByPage

## 请求参数

## Header参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|必须|签名认证 ⽣成认证信息|
|Content-Type|string|必须|设置为application/json|
|Accept|string|必须|设置为application/json|

## body参数

|名称|类型|必<br>须|描述|
|---|---|---|---|
|pageNum|Integer|必<br>须|当前⻚码|
|pageSize|Integer|必|每⻚⾏数|
|||须||
|fileNameOrOrderCode|String|否|⽂件名称/订单编号/客⼾⾃定义编号|

|orderStatus|Integer|否|订单状态(0:已取消,1:待审核,2:待付款,3:⽀付完成,4:⽣<br>产中,5:已发货) -1:表⽰查询所有的数据 但不包括已取消<br>的数据|
|startDate|String|否|开始⽇期|
|endDate|String|否|结束⽇期|

## 响应参数

|名称|类型|描述|
|---|---|---|
|data|SelectOpPageOrderResponseVO|订单分⻚信息VO|

## SelectOpPageOrderResponseVO

|名称|类型|描述|
|---|---|---|
|selectOrderVOList|List< SelectOpOrderVO>|查询订单VO|
|totalRows|Long|总记录数|

|名称|类型|描述|
|---|---|---|
|selectOrderInfoVO|SelectOpOrderInfoVO|订单信息|
|selectOrderDetailsVO|SelectOpOrderDetailsVO|订单详情信息|
|orderItemVOS|List< OrderOpItemVO>|订单商品信息|
