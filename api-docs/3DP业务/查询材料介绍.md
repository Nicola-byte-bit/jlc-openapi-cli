# 15.查询所有已启⽤的材料介绍

## 基本信息

请求⽅式：POST

请求路径：/3dp-open/order/getOPAllEnableMaterialManual

## 请求参数

### Header参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|必须|签名认证 ⽣成认证信息|
|Content-Type|string|必须|设置为application/json|
|Accept|string|必须|设置为application/json|

## 响应参数

|名称|类型|描述|
|---|---|---|
|data|List<OPMaterialTypeManual>|材料介绍列表|

### OPMaterialTypeManual 材料类型介绍 参数

|名称|类型|描述|
|---|---|---|
|materialTypeId|Integer|材料类型Id|
|materialType|String|材料类型名称|
|materialIntroduction|String|材料类型介绍（带⽹⻚标签）|
|opMaterialManualList|List<OPMaterialManual>|材料介绍列表|

### OPMaterialManual 材料介绍 参数

|名称|类型|描述|
|---|---|---|
|materialAccessId|String|材料业务id|

|materialName|String|材料名称|
|applicability|String|适⽤范围|
|strengths|String|优势|
|weaknesses|String|劣势|
|pictureUrlList|List|材料图⽚展⽰|
|attribute|List<MaterialAttributeVo>|材料属性|

MaterialAttributeVo 材料属性 参数

|名称|类型|描述|
|---|---|---|
|name|String|属性名称|
|value|String|属性值|

## 请求⽰例

```
 GET /3dp-open/order/getOPAllEnableMaterialManual
```
