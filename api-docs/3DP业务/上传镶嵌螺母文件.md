# 基本信息

请求方式：POST

请求路径：/3dp-open/order/uploadNutFile

# 请求参数

# Header 参数

|名称|类型|必须|描述|
|---|---|---|---|
|Authorization|string|必须|签名认证生成认证信息|
|Content-Type|string|必须|设置为multipart/form-data|
|Accept|string|必须|设置为application/json|

# Form Data 参数

|名称|类型|必须|描述|
|---|---|---|---|
|file|File|必须|图纸文件，只能上传png,pdf类型的文件|
|meta|String|非必须|值设置为{}, 非sdk接入时，用作生成签名使用|

# 响应参数

|名称|类型|描述|
|---|---|---|
|data|String|文件业务id，后续使用id进行报价或提交订单|

# 请求示例

curl --location --request POST 'https://open-api.jlc.com/3dp-open/ord er/uploadNutFile' \

--header 'Authorization: 签名' \

--header 'Content-Type: multipart/form-data' \

--form 'file=@"2.png"'

# 响应示例

{"code":200,"message":null,"data":"8645723386755059712","successful": true}

|错误码|错误码描述|
|---|---|
|200|请求成功|
|500|请求失败|
