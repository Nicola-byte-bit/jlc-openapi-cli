# 返单接口

## 返单接口 基本信息

## **请求方式** ：POST

## **请求路径** ：/3dp-open/order/returnOrder

## 请求参数

## Header参数

|**名称**|**类型**|**必须**|**描述**|
|---|---|---|---|
|Authorization|string|必须|签名认证 生成认证信息|
|Content-Type|string|必须|设置为 application/json|
|Accept|string|必须|设置为 application/json|

## body参数

|**名称**|**类型**|**必须**|**描述**|
|---|---|---|---|
|orderAccessId|String|必须|原订单业务id|
|returnOrderItems|List< ReturnOrderItem>|必须|返单商品信息|

ReturnOrderItem（返单商品信息 returnOrderItems 元素）

|**名称**|**类型**|**必须**|**描述**|
|---|---|---|---|
|itemAccessId|String|必须|商品业务id|
|itemCount|Integer|必须|返单数量|

## 响应参数

|**名称**|**类型**|**描述**|
|---|---|---|
|data|SubmitOrderResult|返单结果|

## SubmitOrderResult

|**名称**|**类型**|**描述**|
|---|---|---|
|submitOrderVOList|List< SubmitOrderVO>|订单详情|

## SubmitOrderVO

|**名称**|**类型**|**描述**|
|---|---|---|
|orderAccessId|String|订单业务id|
|orderCode|String|订单编号|
|payableAmount|BigDecimal|应付金额|

## 请求示例

```
{
"orderAccessId": "4d1454e71bd641e5866cb47d0fcab65c",
"returnOrderItems": [
    {
"itemAccessId": "a1b2c3d4e5f60718293a4b5c6d7e8f90",
"itemCount": 2
    }
  ]
}
```

## 响应示例

```
{
"code": 200,
"message": null,
"data": {
"submitOrderVOList": [
      {
"orderAccessId": "4d1454e71bd641e5866cb47d0fcab65c",
"orderCode": "ORD20261015001",
"payableAmount": 128.50
      }
    ]
  },
"successful": true
}
```

**错误码 错误码描述** 200 请求成功

**错误码 错误码描述** 500 请求失败
